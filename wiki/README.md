## 一句话定位

**业务事实与授权只有一个来源，AI 只负责分析、检索和建议，高风险动作必须人工确认后由后端执行。**

## 维护约定

- 燃尽图由 `wiki/tools/burndown.mjs` 从 `specs/tasks.md` 的 git 历史生成，不手工改图。
- 页面只写可核对的结论；涉及未验证能力时明确标注“未验证”。
- 代码位置以仓库当前路径为准，`docs/` 与 `specs/` 保留在本地、不随仓库发布。

## 发布到 GitHub Wiki

1. 在仓库 `Settings → Features` 勾选 `Wikis`，并先创建一页 `Home`；
2. 在本地执行：

```powershell
powershell -File wiki/publish.ps1
```

脚本会克隆 `*.wiki.git`，复制页面与 `assets/`，提交并推送。`_Sidebar.md` 与 `_Footer.md` 会被 GitHub Wiki 自动识别。

Wiki 仓库是独立 git 仓库，主仓库的提交不会自动同步；每次修改 `wiki/` 后需要重新执行发布脚本。
