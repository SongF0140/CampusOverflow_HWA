# 测试与验证

## 分层策略

开发期只跑冒烟，全量回归交给 CI：

| 阶段 | 跑什么 |
| --- | --- |
| 每改一小块 | 相关测试文件 + 所属服务 lint |
| 涉及表结构 | 另跑 `uv run alembic upgrade head` |
| 推送 / 提 PR / 批次收口 | CI 全量必须绿 |

分层只改变“何时执行”，不降低“必须编写”。

## 命令

```bash
# 后端（campus-overflow-ai/backend）
uv run pytest tests/test_<模块>.py -q
uv run ruff check .
uv run lint-imports
uv run alembic upgrade head

# 前端（campus-overflow-ai/frontend）
npm test -- <相关测试文件>
npm run lint
npm run check:rules
npx tsc --noEmit

# Agent（campus-overflow-ai/agent）
npm test -- <相关测试文件>
npm run typecheck
npm run lint

# 对比实验（Cross_testing）
npm test
npm run rag

# 真实 MySQL 并发（先启动 deploy/test-sandbox）
$env:TEST_MYSQL_URL="mysql+pymysql://root:sandbox_root@127.0.0.1:3307/campus_overflow_test?charset=utf8mb4"
uv run pytest tests/test_patrol_scan_concurrency_mysql.py -q
```

## 必须覆盖的高风险路径

这些路径不能用“整体跑通”替代：

| 类别 | 要验证什么 |
| --- | --- |
| 权限 | 越权 403/404、非本课程教师、学生不可见管理端 |
| 事务与并发 | 单次副作用、重复批准幂等、旧版本/旧游标拒绝 |
| 治理 | AI 只能建 pending 工单，不能直接处置 |
| 记忆与隐私 | 账号隔离、可清空、敏感信息过滤、记忆不作授权 |
| 工具白名单 | 未注册工具、scope 不足、凭证过期一律拒绝 |
| 可观测性 | trace id 透传、审计失败不返回成功 |

## 典型用例

| 功能 | 覆盖点 |
| --- | --- |
| 全量扫描 | 游标推进、取消生效、单条失败隔离、上限生效、活动任务唯一 |
| 周报导出 | 越权、周外过滤、CSV 公式注入、BOM |
| MCP 接入 | 主/备双 token、过期拒绝、限流不触发工具执行 |
| 问答快照 | 分页、上限、游标停滞、槽切换、过期回退、候选复核 |

## 并发与唯一性

“同一时刻只允许一个活动任务”不能靠先查后插：

- 表上设置唯一槽位列，活动任务占用固定值，终态置空；
- 唯一索引利用“多个 NULL 不冲突”实现原子互斥；
- 并发请求即使同时通过预检查，也只有一个能提交成功；
- 测试覆盖数据库层拒绝与“预检查被绕过”两种情形。

## 当前限制

- 真实 MySQL 并发用例已提供，但默认跳过，需先启动 `deploy/test-sandbox` 并设置 `TEST_MYSQL_URL`。
- RAG 评测使用合成 fixture，只能验证管线，不能验证检索质量。
- 生产部署、多实例调度与告警尚未验证。
