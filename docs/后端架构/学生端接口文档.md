# 学生端接口文档

## 1. 认证与用户（identity）

### POST /api/auth/register —— 注册（US-02）

1. 谁调用？未登录访客。
2. 传什么？

   | 字段 | 类型 | 必填 | 说明 |
   | ---- | ---- | ---- | ---- |
   | username | string | 是 | 用户名，唯一，3~50 字符 |
   | email | string | 是 | 邮箱，唯一，格式校验 |
   | password | string | 是 | 6~100 位（T-02 实现约束）；bcrypt 哈希存储，日志不落明文 |
   | role | string | 是 | `student` / `teacher`（管理员不由注册产生）；**当前 T-02 实现固定注册为 student，role 入参随后续任务与 spec 对齐** |

3. 回什么？`{ code: 200, data: { id, username, role }, message: "ok" }`
4. 错了怎么办？邮箱 / 用户名重复或格式错误 → 400；缺字段 → 400。

### POST /api/auth/login —— 登录（US-02）

1. 谁调用？未登录访客。
2. 传什么？`{ account, password }`（account 支持用户名或邮箱，T-02 实现）。
3. 回什么？`{ code: 200, data: { access_token, token_type: "bearer", user: { id, username, role, reputation_score, ... } } }`；助教能力位标识（字段随 T-02a 落定）。
4. 错了怎么办？凭证错误 → 401（"账号或密码错误"）；被封禁 → 403（"账号已被封禁，请联系管理员"）；缺字段 → 400。

### POST /api/auth/logout —— 退出（US-02，紧凑条目）

登录用户；无 body；回 `{ code: 200 }`；未登录 → 401。

### GET /api/users/me —— 当前用户信息（US-02）

1. 谁调用？登录用户（页面鉴权依赖此接口）。
2. 传什么？无（JWT 即凭证）。
3. 回什么？`{ id, username, email, role, reputationScore, 身份类型与助教认证状态（字段随 T-02a 落定）, createdAt }`
4. 错了怎么办？未登录 / token 失效 → 401。

### PATCH /api/users/me —— 资料编辑（US-02，紧凑条目）

登录用户；body 传可改字段（昵称 / 头像等，密码修改需 `oldPassword`）；回更新后 user；邮箱改为重复值 → 400；未登录 → 401。

### GET /api/users/{id}/reputation —— 用户公开声誉（US-08）

1. 谁调用？登录用户。
2. 传什么？路径参数 `id`。
3. 回什么？`{ userId, username, reputationScore, questionCount, answerCount }`（**不含积分流水**，E-11）。
4. 错了怎么办？用户不存在 → 404。

## 2. 课程（courses）

### GET /api/courses —— 课程列表（US-10）

1. 谁调用？登录用户。
2. 传什么？query：`page`、`page_size`、`keyword?`（名称 / 编码）、`semester?`。
3. 回什么？`{ items: [{ id, name, code, teacherName, memberCount, questionCount }], total }`
4. 错了怎么办？未登录 → 401。

### GET /api/courses/{id} —— 课程详情（US-10）

1. 谁调用？登录用户。
2. 传什么？路径参数 `id`。
3. 回什么？`{ id, name, code, description, teacher, joined, aggregates: { hotQuestions, tags, activeUsers, frequentQuestions } }`（聚合区块无数据时返回空数组）。
4. 错了怎么办？课程不存在 → 404；未登录 → 401。

### POST /api/courses/{id}/join —— 加入课程（US-10）

1. 谁调用？登录学生。
2. 传什么？无 body。
3. 回什么？`{ code: 200, data: { joined: true } }`
4. 错了怎么办？已加入 → 400；课程不存在 → 404；未登录 → 401。

### DELETE /api/courses/{id}/members/me —— 退出课程（US-10，紧凑条目）

登录学生（仅本人）；回 `{ joined: false }`；未加入 → 400；课程不存在 → 404。

## 3. 问题与标签（qa）

### POST /api/questions —— 发布问题（US-03、E-01/E-02/E-07、X-03）

1. 谁调用？登录用户；未登录 → 401；被封禁 → 403（E-07）。
2. 传什么？

   | 字段 | 类型 | 必填 | 说明 |
   | ---- | ---- | ---- | ---- |
   | title | string | 是 | 最长 100 字 |
   | body | string | 是 | Markdown 正文；入库前 bleach 清洗（X-03）；长度上限随 plan 落定，超限截断提示（E-02） |
   | courseId | string | 是 | 已加入的课程 |
   | tagIds | string[] | 否 | 最多 5 个 |

3. 回什么？`{ code: 200, data: { id, title, status: "published", createdAt }, message: "ok" }`
4. 错了怎么办？空标题 / 正文 → 400（E-01）；未加入课程 → 403；课程不存在 → 404。含脚本的 body 被清洗后正常入库，不报错（X-03）。

> 事件钩子：service 内 `# TODO(agent): QuestionPosted`（一期仅注释）。

### GET /api/questions —— 问题列表（US-03、US-09）

1. 谁调用？登录用户。
2. 传什么？query：`page`、`page_size`、`course_id?`、`tag_id?`、`sort=latest|hot`、`unresolved?`、`keyword?`（与 /api/search 共用查询逻辑）。
3. 回什么？`{ items: [{ id, title, courseId, author, tags, status, voteScore, answerCount, viewCount, hasAccepted, createdAt }], total }`（已软删内容不出现在结果中，E-10）。
4. 错了怎么办？未登录 → 401；非法 sort 值 → 400。

### GET /api/questions/{id} —— 问题详情（US-03）

1. 谁调用？登录用户；浏览数 +1。
2. 传什么？路径参数 `id`。
3. 回什么？`{ id, title, body(已清洗 HTML), courseId, author, tags, status, voteScore, myVote, acceptedAnswerId, viewCount, createdAt, updatedAt }`（回答 / 评论经 §4、§5 接口分页获取）。
4. 错了怎么办？不存在或已软删 → 404（E-10）。

### PATCH /api/questions/{id} · DELETE /api/questions/{id} —— 编辑 / 软删除（US-03，紧凑条目）

仅作者（DELETE 另允许管理员）；body 同发布（可部分字段）；DELETE 无 body；软删除后普通列表与详情不可见（E-10）；非作者 → 403；不存在 → 404。删除需前端二次确认（Q-01，前端二期实现）。

### GET /api/tags —— 标签列表（US-03）

登录用户；query `keyword?`、`hot?`；回 `{ items: [{ id, name, type, questionCount }] }`；401。

### POST /api/questions/{id}/tags —— 问题绑定标签（US-03、E-03）

1. 谁调用？问题作者。
2. 传什么？`{ tagIds: string[] }`（新自定义标签以 `name` 内联提交，type=custom）。
3. 回什么？`{ code: 200, data: { tags: [{ id, name, type }] } }`
4. 错了怎么办？重复绑定同一标签 → 400（E-03）；非作者 → 403；问题不存在 → 404。

> AI 推荐标签：用户确认后才调用本接口写入（E-09）；推荐本身为二期 Agent 能力，本期仅落"确认后写入"的接口语义。

## 4. 回答与采纳（qa）

### GET /api/questions/{id}/answers —— 回答列表（US-04）

登录用户；query `sort=latest|votes|accepted`、`page`；回 `{ items: [{ id, author, body(已清洗), voteScore, myVote, isAccepted, recommendedByAssistant, createdAt }], total }`；问题不存在 → 404。

### POST /api/questions/{id}/answers —— 回答问题（US-04、E-07）

1. 谁调用？登录用户；被封禁 → 403（E-07）。
2. 传什么？`{ body }`（Markdown，入库前清洗 X-03）。
3. 回什么？`{ code: 200, data: { id, status: "published", createdAt } }`
4. 错了怎么办？空内容 → 400（E-01）；问题不存在 / 已删 → 404。

### PATCH /api/answers/{id} · DELETE /api/answers/{id} —— 编辑 / 软删除（US-04，紧凑条目）

仅作者（DELETE 另允许管理员）；软删除；非作者 → 403；不存在 → 404。

### POST /api/answers/{id}/accept —— 采纳（US-06、E-05/E-06）

1. 谁调用？**仅提问者**；未登录 → 401；其他用户 → 403（E-06）。
2. 传什么？无 body。
3. 回什么？`{ code: 200, data: { accepted: true, questionStatus: "resolved" } }`；同一事务内：问题置采纳 + 状态 resolved → 回答者 +15 声誉（流水）→ 回答者通知；任一步失败整体回滚（架构说明第 4.B 节）。
4. 错了怎么办？非提问者 → 403（E-06）；该问题已有采纳 → 400（E-05）；回答不存在 → 404。

### POST /api/answers/{id}/recommend —— 助教推荐回答标记（US-20、E-12/E-13）

1. 谁调用？**`require_graduate_assistant`**：研究生身份且助教认证通过；本科生 / 未认证研究生 → 403（E-12）。
2. 传什么？`{ recommended: boolean }`（true 标记 / false 取消）。
3. 回什么？`{ code: 200, data: { answerId, recommendedByAssistant: true } }`；**仅展示标记**：不改问题状态、不影响采纳权（E-13）。
4. 错了怎么办？无助教能力位 → 403；回答不存在 / 已删 → 404。路径为建议值，随 T-05 实施落定并回填 plan 第 5 节。

## 5. 评论（qa）

### GET /api/questions/{id}/comments · GET /api/answers/{id}/comments —— 评论列表（US-05）

登录用户；query `page`；回 `{ items: [{ id, author, body, parentId, createdAt, replies: [...] }] }`（二级回复按 `parentId` 归组）；目标不存在 → 404。

### POST /api/questions/{id}/comments · POST /api/answers/{id}/comments —— 发表评论（US-05、E-07）

1. 谁调用？登录用户；被封禁 → 403。
2. 传什么？`{ body, parentId? }`（parentId 实现二级回复）。
3. 回什么？`{ code: 200, data: { id, parentId, createdAt } }`
4. 错了怎么办？空评论 → 400（E-01）；目标不存在 → 404。成功后触发被评论者通知（§8）。

### DELETE /api/comments/{id} —— 删除评论（US-05，紧凑条目）

仅作者（管理员可删违规评论）；软删除；非作者且非管理员 → 403；不存在 → 404。

## 6. 投票与声誉（interaction）

### POST /api/votes —— 投票（US-07、E-04）

1. 谁调用？登录用户；被封禁 → 403。
2. 传什么？`{ targetType: "question"|"answer", targetId, value: 1|-1 }`。
3. 回什么？`{ code: 200, data: { voteScore, myVote } }`；toggle 语义：重复同方向 = 取消；点赞给作者 +10、点踩 -2，均写流水（US-08）。
4. 错了怎么办？value 非法 → 400；目标不存在 → 404；同一用户对同一内容仅一条有效投票（E-04，唯一约束）。

### GET /api/reputation/me —— 我的积分与流水（US-08、E-11）

1. 谁调用？仅本人。
2. 传什么？query `page?`（流水分页）。
3. 回什么？`{ score, logs: [{ delta, reason, refType, refId, createdAt }] }`
4. 错了怎么办？未登录 → 401。

### GET /api/reputation/rank —— 积分榜单（US-08）

1. 谁调用？登录用户。
2. 传什么？query：`period=week|month|all`、`courseId?`。
3. 回什么？`{ items: [{ userId, username, score }] }`；内存实现，无 Redis（Q-04）。
4. 错了怎么办？非法 period → 400；未登录 → 401。

## 7. 搜索（discovery，纯读）

### GET /api/search —— 综合搜索（US-09）

1. 谁调用？登录用户。
2. 传什么？query：`q`（必填，命中标题或正文）、`courseId?`、`tagId?`、`sort=latest|hot`、`unresolved?`、`page`。
3. 回什么？`{ items: [问题卡片], total }`（与 GET /api/questions 共用查询逻辑；相关问题 / 热门列表复用本接口参数组合）。
4. 错了怎么办？缺 q → 400；未登录 → 401。

## 8. 通知（interaction）

### GET /api/notifications —— 我的通知（US-15、E-11）

1. 谁调用？仅本人。
2. 传什么？query：`unreadOnly?`、`page`。
3. 回什么？`{ items: [{ id, type, title, link, isRead, createdAt }], unreadCount, total }`；触发来源：被回答 / 被评论 / 被采纳 /（二期）审核结果。
4. 错了怎么办？未登录 → 401；他人通知不可见（E-11）。

### POST /api/notifications/{id}/read · POST /api/notifications/read-all —— 已读（紧凑条目）

登录用户；回 `{ unreadCount }`；单条已读 id 不存在或非本人 → 404。
