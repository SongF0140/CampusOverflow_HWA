## 问题与复现

### B-001／P1：三端助手页面崩溃

分别登录后打开：

- 学生 `/assistant`
- 教师 `/teacher/assistant`
- 管理员 `/admin/agent/assistant`

页面最终显示 `This page couldn’t load`。教师刷新后再次出现；三端控制台均记录：

```text
TypeError: crypto.randomUUID is not a function
```

影响：助手无法进入，无法验证模型回答、SSE、新会话、渐进式记忆与治理提议。

定位线索：当前入口为公网 HTTP；本地代码 `browser-sessions.ts` 的 createBrowserSession 与 `useServerChat.ts` 初始化直接调用 crypto.randomUUID。应核对部署 SHA，再处理 HTTPS 与浏览器能力检测／兼容策略。不应通过关闭浏览器安全保护来验收。

### B-002／P1（需独立多角色登录时）：跨端口账号互相覆盖

复现：教师端登录 gl_teacher，再在管理员端登录 gl_admin1，教师工作台显示 gl_admin1 管理员；学生端登录 gl_student 后，教师页刷新显示 gl_student 并返回 403，管理员端刷新也拦截教师身份。

推断为相同主机、同名认证 Cookie 跨端口共享；未读取 Cookie 值，不据此断言具体 Set-Cookie 属性。不同端口不是 Cookie 的隔离范围。若需求是同时登录三种账号，需隔离浏览器配置文件或设计独立站点／Cookie 策略；若选择统一登录，需同步多页身份并明确切换提示。

未观察到越权放行，但旧页面会短暂保留原身份和页面内容，跨标签状态一致性需要补测。

### B-003／P2：教师在榜单／热门用户被标为学生

学生首页热门用户与排行榜中 gl_teacher 显示“学生”；教师工作台及管理员用户管理中，同一用户 #3 明确显示“教师”。需要检查榜单／用户卡片数据契约与默认角色映射。

### B-004／P2：管理员课程表缺失已存在的学期

教师课程 #11 详情显示“2026秋”，管理员课程管理第二页中，同一课程 SE-DEMO-2026F 的学期列显示“—”。检查管理列表字段映射。状态列也为“—”，但尚无对照证据，不单独认定状态字段错误。

### B-005／功能缺口：教师工作台仍有占位

教师工单区明确显示“教师端工单接口尚未开放；治理接口当前仅管理员可调”。动态调课暂无通知、周报暂无报告属于空数据，不能直接归类为接口故障。学生主导航、个人中心及已检查课程页未发现聊天入口；路由 `/assistant` 存在但存在 B-001，入口可发现性需核对设计。

### B-006／展示待核对：已提交业务与外围工具错误的区分

历史运行 execution-6f6be711-60b7-45ce-a7b1-587e3052743d 顶部“已成功”、步骤“步骤成功”，工具行显示“失败”，结果摘要为“后端已执行并保存回执”。这可能是已提交后外围 Hook／响应失败的合法情况，不能据此认定重复执行或事务错误；建议 UI 分开显示业务提交结果和外围调用错误，避免误导管理员重试。
