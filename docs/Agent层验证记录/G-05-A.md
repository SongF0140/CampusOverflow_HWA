# G-05-A 模型异常结束校验

日期：2026-10-22。依据 AG-R02/03、C-05/C-08、specs/plan.md 与 Agent 层首批实施计划；实现验证完成，人工待审查。

## 实现与边界

规划与结构化任务共用结束检查，只有 stop 可成功。SDK 返回合法 JSON 但结束原因是 length、content-filter、error、other 或 tool-calls 时，不消费结果、不执行后续工具、不进入结构修复重试。SDK 无文本/JSON 解析失败时，检查 NoObjectGeneratedError 的结束原因，正常停止的结构校验重试保留既有行为。

聊天消费 fullStream，error/abort 事件直接失败，完成后再检查 finishReason。缺失结束帧不能成功；只有正常结束且成功终态落库后才发送 done。失败走已有 failed 审计，HTTP 错误与 SSE error 保留运行关联，不泄露提供商异常正文；禁用 SDK 默认原始异常日志输出，由完整事件流处理错误。已输出的 delta 是未完成片段，无法撤回。

未修改 app.ts、后端状态契约和数据库。G-05 的整体 180 秒、单次模型 60 秒、主动取消传播、模型来源自检和累计返工尚未完成；检测异常结束不代表实现主动取消。SDK 自带传输重试策略留后续预算块收口。
