# G-03-U1 运行预算与执行前复核

日期：2026-10-22。依据：AG-R02、C-05/C-06，specs/plan.md 的 G-03-U1，首批实施计划。G-03-C 已获用户继续授权，本块为统一规划前的执行基础，人工待审查。

## 实现

- RunContext 创建独立且不可替换的工具预算，累计值封闭存储；执行器不再接受 spentToolCalls，四类任务传入同一个运行上下文。
- 每次实际调用前扣减一次，工具失败计入；后续引用异常或预算异常不丢失累计值，上限仍为 12，计划步骤上限仍为 8。
- 每步调用前检查工具是否仍注册、提供实现且为低风险；后端 401/403 立即终止，普通故障继续保留原有 failures 语义。
- 引用路径只读取对象/数组自有属性，不读取继承字段或稀疏数组的原型索引。

## 决策与限制

用运行对象持有预算，避免调用方在计划异常后拿不到返回次数或漏传，失败调用不会返还额度。身份失效由执行器直接终止，避免任务只检查首个普通错误而漏掉后续撤权。后端仍是逐次数据权限的真值源，本块的工具风险复核不代替后端授权。

本块无新依赖、迁移或后端/前端修改，app.ts 未修改。现有任务模板与聊天 SDK 工具循环仍待 U2 统一；U1 预算已接入四类任务的计划执行，不代表旧聊天循环已受该预算控制。最多一次返工、整体超时取消与持久观测仍按 G-04/G-05 收口。测试使用模拟模型/客户端，无真实模型或数据库联调声明。
