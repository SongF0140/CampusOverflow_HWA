# GL-07 服务端私人上下文

## 设计依据

用户批准管理员记忆/会话服务器保存，与中台分文件夹；GL-R05/06及C-07。学生和教师仍使用浏览器，不静默迁移。根目录AGENTS、GL计划第GL-07节、既有memory/session契约已阅读。

## 实现与配置

后端配置`BACKEND_PRIVATE_CONTEXT_ROOT`为私有磁盘目录；默认空表示未启用，不能回退读取旧浏览器数据。目录不能放在public/static下。保存布局：`admin/u_<id>/memory.json`、`admin/u_<id>/sessions/<服务器UUID>.json`；中台为`platform/c_<client_id>/u_<id>/sessions/...`。每次按数据库当前管理员身份和认证来源授权，不接受请求自报路径/source/client_id。

中台后端`BACKEND_EXTERNAL_AGENT_KEYS`条目可增加稳定UUID字段`client_id`；原三字段凭证映射继续兼容，但未配client_id时私人会话明确不可用。轮换密钥保持client_id可保留目录；不同客户端和账号不能串读。同一账号的admin/platform互不可读；中台没有管理员个人memory。

文件层使用跨进程文件锁、版本比较、临时文件fsync及原子替换。损坏数据拒绝写入而非当空覆盖，错误不返回磁盘路径。删除会话保留无正文的版本墓碑，旧响应不能重建；记忆清空保留递增版本。单账号最多20会话、每会话100消息及文件大小限制；个人记忆50条/条500字。凭证格式与敏感记忆拒绝保存。

## 验证记录

先运行缺失配置/接口反例，再实现。新增后端8项（账号/来源/客户端隔离、敏感内容、并发版本冲突、路径/来源伪造、损坏格式、导入幂等和删除墓碑）；相关3文件43 passed，ruff及5条分层契约通过，无新迁移。测试全部用临时目录，不启用实际私人存储。

Agent新增中台会话MCP测试通过，全量43文件402 passed，类型/eslint通过。私人工具只能操作认证客户端目录，参数/结果正文不写MCP审计。管理员渐进披露从服务器核对条目及会话归属，最终聊天重新读取服务器历史与当前记忆，不能复用已清空记忆。

前端管理员使用独立服务器适配器，学生/教师原浏览器回归通过。管理员刷新恢复历史、切换账号拒绝旧响应、清空后迟到流不恢复正文已有测试；旧数据只在查看清单并确认后上传，按导入UUID去重，不自动删除本地副本。前端全量80文件495 passed，类型与全量eslint通过。服务端适配器4项新测试通过，覆盖旧浏览器数据不自动上传及迟到响应。

## 决策与限制

后端文件协议可独立于前端重启读取，无进程内数据真值缓存。根目录应由部署者配置私有ACL和备份；未执行磁盘分区、真实迁移或部署。跨实际进程杀停/恢复与服务器磁盘验收仍归GL-06。中台私人会话工具不提供memory、批准或高风险执行能力。只有本人数据进入渐进披露，不把私人内容并入主Agent共享知识。
