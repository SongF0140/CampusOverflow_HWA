# G-04-A 用户归属的持久写入契约

日期：2026-10-22。依据：AG-R01/03、C-05/C-08、D-2/D-7/D-8/D-9，specs/plan.md 与首批实施计划。用户已通过 U2 并授权继续，本块实现验证完成、人工待审查。

## 实现与边界

- agent_runs 增加可空 user_id 与索引，作为归属快照；历史记录为 null，不推断归属，不设删除级联外键。
- 新增 POST /internal/agent/user/runs、PATCH /internal/agent/user/runs/{agent_run_id}、POST /internal/agent/user/tool-calls；必须同时有服务与当前用户凭证，归属取后端身份，创建 trace 取服务依赖解析的请求头。请求体自报 user_id/role/trace_id 不能改变归属或 trace。
- 更新及工具写入锁定运行后检查归属。他人（含 admin）与无主运行对用户入口返回 404；旧服务入口只能修改无主运行，不能作为回退旁路。
- 运行终态不可再次迁移或追加工具；工具日志的 trace 来自父运行。重复运行 ID 唯一键冲突回滚，返回 409，不覆盖原记录。
- 摘要经后端纯领域规则脱敏后压平并截断到 200 字，覆盖 JSON/键值密码、Bearer、Cookie、中文密钥字段及完整私钥块；完整私钥先移除再截断。新接口声明具体成功响应模型。

## 决策与限制

用户归属是后端认证结果，不能把服务持有 token 等同于可访问任何用户运行；管理员管理审计由独立能力接入，本入口不提供角色旁路。父运行行锁用于保护写入与终态检查；SQLite 结果不证明 MySQL 并发行为已验收。

摘要规则是模式脱敏与长度保护，不是完整隐私语义识别器；G-04-B 的 Agent 记录器必须优先发送安全元数据摘要，不能将完整输入/工具正文交给后端后就声称安全。

只验证本次增量迁移，不代表在 SQLite 上跑通完整 MySQL 历史链，也未连接或迁移现有业务数据库。Agent 源码、前端和 app.ts 未修改；生产 Agent 当前仍用内存记录器。计划/步骤记录、异步记录器与审计失败停止执行归 G-04-B；G-04 整体、G-05/G-06 未完成。
