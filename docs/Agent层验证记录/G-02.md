# G-02 用户身份链路验证记录

日期：2026-10-18。状态：实现验证完成；用户于 2026-10-21 确认审查通过，记录见 docs/审查记录/G-02用户身份链路/审查记录.md。

## 设计依据

用户已通过 G-01 审查并授权继续。依据 AG-R01/AG-R02、C-05/C-08、plan G-02 与《Agent层首批实施计划》。此前公开业务接口要求登录但允许读取共享课程/公开问题/标签，新增路径沿用该规则，不擅自增加仅选课成员可读的限制。隐藏、删除过滤复用后端查询；不授予记忆、成员管理或治理权限。

## 实现内容

- BFF 从 HttpOnly co_token 提取用户 JWT，只转发受控请求头、trace_id 与请求取消信号。坏 Cookie 不导致 500，不使用客户端自报 Authorization 或角色/用户/服务身份。
- Agent 除健康探针外先请求后端 principal；失败不调用模型、不创建运行记录。响应经 Zod 验证并冻结，凭证不进入 principal、模型参数和记录器。
- 新增 /internal/agent/user/courses/search、/user/questions/search、/user/tags 双凭证只读入口，每次数据调用验证当前用户。保留原服务入口契约；用户客户端不回落到服务身份。
- 每请求独立客户端和工具注册表，避免首个客户端被模块单例持有。旧独立工具测试使用默认注册表，HTTP 运行不使用它。
- 默认推荐任务使用已认证客户端；修正 course_id 参数及蛇形响应映射。身份失效的 401/403 终止结构化任务，其他词表故障保留既有语义匹配降级。
- 检索结果亦作 Zod 验证，仅保留所需字段。后端 fetch 默认 60 秒超时，传播请求取消，禁止重定向携带凭证。整体模型预算与取消终态仍归 G-05。
- app.ts 收敛为装配入口，聊天、结构化任务、共享运行/错误处理拆入 routes/，各新函数保持小范围。

## 决策与限制

不复制 JWT 签名密钥至 Agent，不新增前端自报身份通道。不全局修改原服务接口认证，以 user 前缀表明用户级调用并减少旧内部契约回归。未新增依赖或数据库结构，不需要迁移。

测试使用模拟 LLM、模拟 fetch 与 SQLite 基建；不声称已完成真实三服务网络、MySQL 或模型联调。运行摘要仍在内存，归属持久化与审计失败阻断由 G-04 交付；运行上下文可选 principal 仅为保留纯循环单测和旧独立 helper 的类型兼容，生产 HTTP 路由强制注入可信 principal。模型生成全程取消、崩溃恢复和重放不在本块完成范围。个人记忆、Wiki 与后台调度尚未开放。
