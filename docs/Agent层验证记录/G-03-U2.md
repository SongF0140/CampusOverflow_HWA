# G-03-U2 统一模型规划入口

日期：2026-10-22。依据：AG-R02、C-05/C-06，specs/plan.md G-03-U2，首批实施计划。用户已审查 U1 并授权继续；本块实现验证完成、人工待审查。

## 实现

生产链路统一为：可信身份 → 请求级工具集 → 模型 PlanList → 程序校验/顺序执行 → 结果生成。新增 loop/planned-tools.ts 共用规划提示词、任务工具裁剪、必需工具和任务范围检查；沿用 U1 RunContext 累计预算。删除标签、草稿与扫描的固定计划，推荐也改用统一入口。旧 SDK Loop 仅保留辅助测试，HTTP 入口不再使用。

| 任务 | 可用工具 | 必需工具及范围 |
| --- | --- | --- |
| 标签建议 | fetchTags | 至少一次词表读取，真实标签 ID 仍由程序映射 |
| 相似问题 / 文档草稿 | searchCourses、searchQuestions | 至少一次问题检索，指定课程不得省略或改写 |
| 风险扫描 | fetchModerationTarget | 必须读取请求指定类型与 ID 的目标 |
| 聊天 | 现有四个只读工具 | 按需检索，纯知识问题允许零步计划 |

范围检查发生在引用解析后、调用前，错误计划直接失败；普通工具故障仍按原任务约定降级。任务候选/词表按实际步骤收集，正文不再硬编码 s1；401/403 由执行器立即中断。聊天最终流式调用不带工具，仍返回 meta/delta/done/error。移除已不适用的应用装配参数 maxSteps，计划与累计调用上限继续由受控运行常量约束。

## 决策与限制

模型负责选择关键词、步骤和合法工具；白名单、任务范围和调用额度由程序约束。最终生成阶段没有额外工具通道。入口身份拒绝仍零模型调用；若后端在执行检索时才报告失效，计划阶段已经发生，但不再生成最终建议。

独立辅助调用缺少客户端时保留既有无依据/摘录降级；所有生产 HTTP 入口都先校验身份并装配请求级客户端与工具表。普通资料故障允许既定降级不等于非法计划可降级。

无新依赖、迁移、后端或前端修改，app.ts 未修改。G-04 持久记录、G-05 有限返工/整体超时取消/终态校验和 G-06 真实联调尚未实施；模型输出结构校验重试不等于完整 Reflect/返工流程。测试使用模拟模型与网络，不代表真实模型、MySQL 或部署联调验收通过。
