## 决策与限制

复用 get_current_user，不自行解码 JWT 或复制身份查询。路由从轻量 principal 构造明确 schema，不读取 ORM，不引入无业务规则的 service/repository 包装。服务 token 和用户 JWT 必须同时验证，不复用治理决策接口的二选一认证。
