# TW-02 教师与助教优质回答认证

日期：2026-10-28。用户授权连续实施至本项，功能已实现，真实部署迁移未执行。

## 设计依据

AGENTS、constitution C-01/C-02/C-03/C-05、spec TW-R02、现有 qa 负责教师认证与助教推荐契约。用户已确认教师仅本人课程，助教全站可见课程无需加入；本轮另明确确认“不允许助教自我认证，只能认证其他学生回答”。

## 实现与决策

- 新增 certified_by_assistant，与 certified_by_teacher 和 recommended_by_assistant 独立；不把旧推荐自动迁移成认证。
- 复用 POST/DELETE /api/answers/{id}/certify，后端读取当前数据库身份决定来源。有效助教无需加入课程；教师仍限负责课程；管理员、普通学生、被撤销资格及封禁用户拒绝。
- 只对学生回答置位认证，回答与父问题均需可见；助教自己的回答在后端拒绝、前端隐藏入口。
- 两种认证可并存，取消仅改当前身份对应来源，不改另一来源、推荐、问题状态与采纳。
- 回答列表增加 author_role 以收拢前端入口；问题详情和个人主页显示“教师认证”“助教认证”来源。
- GET /internal/agent/user/certified-answers/{answer_id} 双凭证只读回源校验认证卡片，返回 certified/visible/course_id/question_id/answer_id/url。隐藏、删除或父题不可见统一404，不含正文；可见但撤销认证返回 certified=false。真实链接使用既有 #answer-{id} 锚点。
- 迁移 tw02_assistant_cert 添加非空默认 false 认证位，保留旧推荐和教师认证。无模型调用、无真实业务库迁移。

## 限制

- 认证来源是教师/助教类别，当前沿用全局类别标记，没有新增逐认证人历史表；任一具备该来源资格的操作者可按范围取消相应类别认证。
- 作者角色用于入口显示和置位时校验，当前按本页唯一作者读取，未来大列表可补批量角色接口优化。
- 真实MySQL迁移和完整浏览器联调留部署验收，不将隔离SQLite验证表述为线上验收。
