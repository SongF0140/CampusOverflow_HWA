# AP-03 管理端申请与反馈续接入口

日期：2026-10-28。前端独立模块已实现验证，后端与 Agent 合同接线由本批父任务完成。

## 依据与决策

- 复用 AP-02 预览／申请与 AP-03 主动状态读取／resume／cancel 契约，沿用 Approvals A-D01/A-D03/A-D05。
- 用户明确默认等待 7 天，可提前取消；过期和取消只终止 Agent 续接，不撤销工单或后端已完成的真实治理。
- 审核队列增加可折叠 ApprovalRequestPanel，不重设计原审批中心，不让前端或 Agent 自动调用 resolve。
- 先读取并展示后端现状、拟动作影响，再由管理员点击“提交待审核”；请求带唯一 UUID、同一份参数和 state_version。
- 修改任何参数会取消在途预览并清除旧预览；失败重试保留同 UUID，避免未知提交结果导致重复建单。
- 按管理员账号在 localStorage 保存最近一份 request_id/工单编号，便于刷新后主动核对；完整待审清单继续以既有后端审核队列为准，不把浏览器副本作为真值源。
- 界面只通过同源 BFF 调用 Agent API。没有定时轮询、长连接或自动批准；核对、恢复反馈和取消由管理员主动触发。恢复仅消费后端结果，不重放处置。
- 换号／卸载中止请求并丢弃迟到结果；后端仍每次验证当前管理员身份。
