# 前端设计系统（Design System）

> 状态：v1.1（2026-10-04）｜负责：前端（张志轩）
> 依据：`.trae/rules/conventions.md` §5（UI/UX 约定）、《设计技能使用指南》流程、`ui-ux-pro-max` 生成结果、[awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 大厂布局参考
> 适用范围：`campus-overflow-ai/frontend/`。新增页面与组件一律按本文件；token 见第 6 节。

## 1. 视觉约束（禁止 / 允许）

| 禁止 | 允许 |
| --- | --- |
| 蓝紫**渐变**（尤其大面积背景）；大面积高饱和色块；霓虹发光；玻璃拟态；"AI 产品模板感" | 任何**单一**强调色（含蓝、紫、绿）；中性底色；浅色标签底 |

来源：`.trae/rules/conventions.md` §5「视觉风格清爽现代，避免大面积蓝紫渐变和"AI 产品模板感"」。

**注意：禁的是"大面积渐变"这一技法，不是"蓝色/紫色"这两个颜色。**

## 2. 布局规则

| 场景 | 规则 | 来源 |
| --- | --- | --- |
| 阅读页（问题详情、回答区） | 三栏：左导航 240px ｜ 正文最大 720px ｜ 右目录 200px；正文行高 ≥1.5 | Mintlify |
| 列表页（问题广场、课程列表） | 内容最大宽 1280px、左右留白 32px；卡片圆角 12px | Notion |
| 教师端 / 管理端 | 层级用"表面阶梯"（同色系深浅），**不用颜色分区**；表格行高 ≥44px | Linear |
| 按钮 | 圆角 8px **矩形**，不用胶囊形 | Notion |
| 输入框 | 高度 44px；聚焦 = 2px 强调色描边 | Notion |
| **强调色纪律** | **只用于**主按钮 / 焦点环 / 链接强调；**不得**作为区块背景或卡片填充 | Linear |
| 触控与断点 | 触控目标 40–44px；1440 / 1280 / 1024 / 768 / 480 逐档适配 | Linear / Mintlify |

## 3. 颜色

### 3.1 中性底（固定）

| token | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#FFFFFF` | 页面主背景 |
| `panel` | `#F7F7F7` | 侧栏、表头、卡片头、输入框底 |
| `line` | `#E5E5E5` | 所有 1px 描边 |
| `ink` | `#0A0A0A` | 标题与正文 |
| `ink-muted` | `#3A3A3C` | 说明、表单标签 |
| `ink-subtle` | `#888888` | 时间、计数（**对比度下限，不得更浅**） |

### 3.2 强调色（青绿）

| token | 值 | 用途 |
| --- | --- | --- |
| `brand` | `#0F766E` | 主按钮、焦点环、链接强调、选中态 |
| `brand-strong` | `#115E59` | 按下 / 悬停 |
| `brand-soft` | `#CCFBF1` | 选中底、AI 卡片底 |

### 3.3 语义色

成功 `#16A34A`｜警告 `#D97706`｜危险 `#DC2626`

**状态不能只靠颜色区分，必须"色块 + 文字"。**

### 3.4 AI 相关界面

**不新增色相**（不使用紫色）。区分方式：

- 底色 = `brand-soft`；边框 = **1px 虚线**
- 固定图标 + 固定文案「**AI 辅助参考**」
- 三态必显：生成中 / 失败重试 / 待人工确认
- 固定提示「**未确认不会写入**」

## 4. 字体与字号

| 项 | 取值 |
| --- | --- |
| 字体栈 | `Inter, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", -apple-system, "Segoe UI", sans-serif` |
| 字阶 | 页面标题 30–36 ／ 区块标题 20–22 ／ 卡片标题 16 ／ 正文 14.5–15 ／ 辅助 12–13 |
| 行高 | 正文 **1.75**，单行约 72 个中文字符 |
| 字重 | 标题 600，正文 400，按钮 500 |

不引入中文字体文件（体积大）；拉丁/数字回退系统字体亦可接受。

## 5. 动效规范

原则：**只对"状态变化"做动效，不做装饰性动画。**

| 场景 | 时长 | 做法 |
| --- | --- | --- |
| 悬停 / 焦点 | 150ms | 只改颜色、背景、描边（**不做缩放**） |
| 展开 / 折叠 / Tab 切换 | 200ms | 透明度 + 4px 位移 |
| 页面级切换 | 300ms | 淡入 + 4~8px 位移 |
| 列表卡片进场 | 200ms | 错峰 20–40ms，**最多 8 个** |
| 加载态 | — | **骨架屏 + 微光扫过**（不用整页转圈） |

必须支持 `prefers-reduced-motion`：命中时关闭位移与缩放，只保留透明度变化。

实现方式（Tailwind）：位移/缩放类动效统一加 `motion-reduce:` 变体关闭，例如
`transition-transform motion-reduce:transition-none`、`animate-pulse motion-reduce:animate-none`。
**任何新增动效必须同时给出 reduced-motion 降级，否则不予合入。**

**禁止**：装饰性无限动画、hover 缩放（引起布局位移）、超过 500ms 的过渡、全屏 3D/WebGL 炫技效果。

## 6. Tailwind token

定义在 `campus-overflow-ai/frontend/src/app/globals.css`（Tailwind CSS 4，CSS-first）：

```css
@theme {
  /* 中性底 */
  --color-canvas: #ffffff;
  --color-panel: #f7f7f7;
  --color-line: #e5e5e5;
  --color-ink: #0a0a0a;
  --color-ink-muted: #3a3a3c;
  --color-ink-subtle: #888888;

  /* 强调色（青绿） */
  --color-brand: #0f766e;
  --color-brand-strong: #115e59;
  --color-brand-soft: #ccfbf1;

  /* 语义色 */
  --color-success: #16a34a;
  --color-warning: #d97706;
  --color-danger: #dc2626;

  /* 圆角：4 小件 / 8 按钮与输入框 / 12 卡片 */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;

  /* 动效缓动（时长用内置 duration-150 / duration-200 / duration-300） */
  --ease-standard: cubic-bezier(0.2, 0, 0.2, 1);
}
```

用法示例：`bg-canvas`、`text-ink-muted`、`border-line`、`bg-brand`、`text-brand-strong`、`bg-brand-soft`、`rounded-md`、`ease-standard`、`duration-200`。
