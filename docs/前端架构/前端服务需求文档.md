> 格式说明：本文按老师给的《Agent 服务需求文档（第一阶段 MVP）》**同样的骨架**写（定位与边界 → 触发来源 → 功能需求 + 验收标准 → 接口需求 → 非功能 → MVP 验收清单），方便三端文档放在一起评审。
> 对应整体架构图：前端（端口 3000）里的 6 个模块 —— **认证+鉴权 / 提问、投票、采纳等 CRUD 接口对应页面 / 后台管理页面 / Agent 会话页面 / Agent 运行监控页面 / 渲染组件**。
> 配套文件：《交付-手绘版-前端页面设计图.png》（页面与跳转）、《04-前端接口设计文档（30条明细）.md》（接口字段级明细）、《项目整体框架图.png》（整体结构）。

## 1. 服务定位与边界

前端是**一个 Next.js 应用（端口 3000）**，同时承载学生端、教师端、管理端三套页面，负责把用户操作翻译成接口调用、把结果渲染给用户，并通过 BFF 转发所有请求。

**必须做**：

- 一个应用内实现三端：学生端（顶栏布局）、教师端、管理端（侧栏布局），靠路由前缀 + 角色守卫区分。
- 所有页面提供**加载 / 空 / 错误**三种状态；AI 相关页面额外提供**生成中 / 失败重试 / 待人工确认**三种状态。
- 所有请求经同源 BFF 转发：业务接口 `/api/backend/api/**` → FastAPI :8000；AI 接口 `/api/agent/**` → Agent :8787。
- 统一处理统一响应格式 `{ code, data, message }` 与错误码（400/401/403/404/500）。
- 展示 AI 建议时必须标注"AI 辅助参考"，且**用户确认后**才触发写入。
- 界面文案全部简体中文；样式用 Tailwind，清爽现代、无大面积蓝紫渐变。

**禁止做（硬边界）**：

- 不在浏览器直连 FastAPI :8000 / Agent :8787，不接触 MySQL。
- 不在前端保存密钥、token、数据库连接信息；登录态由 BFF 用 HttpOnly Cookie 维护。
- 不自己判定业务权限（例如"能不能采纳""能不能删帖"），一律以后端返回为准。
- 不把 AI 建议直接当作正式内容写入（标签、问答都必须用户确认）。
- 不在页面上暴露他人隐私字段（邮箱、手机号、完整通知内容等）。

## 3. 功能需求

### 3.1 三端布局与页面清单

三端共用一套组件库，布局不同：

| 端 | 使用角色 | 路由前缀 | 布局 | 首屏 |
| -- | -------- | -------- | ---- | ---- |
| 学生端 | 游客、学生、助教、教师、管理员 | `/` | 顶栏 + 内容区 + 右栏 | 问题广场 `/` |
| 教师端 | 教师、助教（管理员可进） | `/teacher` | 左侧栏 + 顶栏 | 教师工作台 `/teacher` |
| 管理端 | 仅管理员 | `/admin` | 左侧栏 + 顶栏 | 治理总览 `/admin` |

**验收标准**：

- 未登录访问受保护页面 → 跳登录页并带 `returnTo`，登录后回原页。
- 角色不匹配（如学生访问 `/admin`）→ 展示无权限页，**不发起请求**。
- 教师只看到自己负责的课程；管理端入口只对管理员显示。

### 3.3 BFF 与请求约定

| 约定 | 内容 |
| ---- | ---- |
| 调用方式 | 浏览器只调同源地址：业务 `/api/backend/api/**`、AI `/api/agent/**` |
| 鉴权 | BFF 注入 `Authorization: Bearer <JWT>`（Cookie 保存登录态），前端组件不读 token |
| 响应 | 统一 `{ code, data, message }`；列表带 `items / total / page / page_size`（接口字段一律蛇形，2026-09-20 定案） |
| 追踪 | 每次请求带 `x-trace-id`，管理端可据此排查 |
| 错误 | 400 行内提示；401 跳登录；403 无权限；404 内容不存在；500 稍后重试并保留草稿 |

**验收标准**：搜索代码里不存在直连 8000 / 8787 的地址；所有 fetch 都走 BFF。

### 3.4 AI 交互（Agent 会话）

| 场景 | 位置 | 交互要求 |
| ---- | ---- | -------- |
| 相似问题推荐 | 发布问题页（输入标题 / 正文后防抖触发） | 展示标题 + 相似度 + 理由，可点进历史问题；无命中时提示"未找到站内相似问题" |
| 标签推荐 | 问题提交后 | 展示标签 + 理由 + 置信度；**用户勾选确认后**才调用写入接口 |
| 内容风险扫描 | 无界面（后端 / Agent 静默执行） | 前端不发起；结果体现在通知与审核闭环 |
| 运行监控 | 管理端运行详情页 | 展示九步时间轴、工具调用、关联工单、失败原因；实时状态轮询失败时退化为手动刷新 |

**验收标准**：

- 三种状态必须可见：生成中 / 失败重试 / 待人工确认。
- AI 服务不可用时，卡片隐藏或提示"暂不可用"，**主流程（提问、回答）不受影响**。
- 未经用户确认，前端不发起任何标签写入请求。

### 3.5 状态与异常处理

| 状态 | 要求 |
| ---- | ---- |
| 加载 | 骨骼屏（列表卡片骨架 / 详情行骨架），不用整页转圈 |
| 空 | 说明"为什么空 + 下一步做什么"，带一个主操作按钮 |
| 错误 | 中文提示 + 重试按钮；500 保留用户已填内容 |
| 权限 | 401 跳登录（带 returnTo）；403 提示无权限；被封禁提示原因 + 申诉入口 |

**验收标准**：逐个页面点一遍，三态齐全；被禁言 / 封禁用户提交内容能看到原因。

### 3.6 权限与可见性

| 区域 | 游客 | 学生 | 助教 | 教师 | 管理员 |
| ---- | ---- | ---- | ---- | ---- | ------ |
| 公开浏览（问题广场 / 课程 / 问题详情 / 用户主页 / 排行榜） | ✅ | ✅ | ✅ | ✅ | ✅ |
| 提问 / 回答 / 评论 / 投票（需登录） | 🔑 | ✅ | ✅ | ✅ | ✅ |
| 个人中心 / 通知 / 我的记忆（仅本人） | 🔑 | ✅ | ✅ | ✅ | ✅ |
| `/teacher/**` | ⛔ | ⛔ | ✅ | ✅ | ✅ |
| `/admin/**` | ⛔ | ⛔ | ⛔ | ⛔ | ✅ |

**验收标准**：越权入口不渲染（不是点了才报错）；服务端仍会二次校验（前端隐藏只是体验）。

## 5. 非功能需求

| 类别 | 要求 |
| ---- | ---- |
| 性能 | 首屏骨架屏不白屏；列表分页；AI 请求不阻塞主流程 |
| 兼容 | 桌面优先（1440 / 1600 / 1920），窄屏可滚动，主导航折叠为抽屉 |
| 可读性 | 正文最大宽度约 72 字符；对比度满足可读性；状态不只靠颜色区分 |
| 文案 | 全简体中文；错误提示写"人话"，不展示堆栈 |
| 风格 | Tailwind 统一色板与间距；无大面积蓝紫渐变；无"AI 产品模板感" |
| 安全 | 不存密钥；Markdown 渲染前 XSS 清洗；不在前端暴露他人隐私 |
| 测试 | vitest 覆盖 hooks 与关键交互；`npm run lint` 零 error、`npm test` 通过 |
