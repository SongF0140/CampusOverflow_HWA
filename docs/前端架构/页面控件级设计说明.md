# 页面控件级设计说明（UI 设计规格 v1）

> 依据：《交付-手绘版-前端页面设计图.png》+《前端服务需求文档.md》3.1~3.6 +《页面版式与页面连接说明.md》。
> 定案约束（2026-10-06）：**AI 页面先不做**（骨架预留位）；图与规格差异**按"取多的一方"合并**（补录"操作结果"页、顶栏"搜索记录"页签）。
> 落点：与 `frontend/src/app/` 现有路由一一对齐；共享控件沉淀到 `src/shared/components`，域内控件放 `src/features/<域>/`。

---

## 0. 全局规范

### 0.1 画布与栅格

| 项 | 规格 |
| ---- | ---- |
| 断点 | 桌面优先：1440 / 1600 / 1920；≤1024 主导航折叠为抽屉，右栏下沉 |
| 内容区 | 最大宽度 1200px 居中；12 列栅格，主区 8 列 + 右栏 4 列 |
| 间距标尺 | Tailwind 刻度：卡片内 12/16px，卡片间 16/24px，区块间 32px |
| 圆角阴影 | 卡片 rounded-xl + 边框 1px（避免重投影"模板感"） |
| 色板 | 中性灰白底 + 单一主色（具体色值由全局 CSS 变量定，**禁大面积蓝紫渐变**）；涨/正向用红、降/负向用绿（中文习惯） |

### 0.2 控件尺寸

| 控件 | 高度 | 说明 |
| ---- | ---- | ---- |
| 主按钮 primary / 次按钮 ghost / 危险按钮 danger | 40px / 36px | 圆角 8px；danger 一律配确认弹窗 |
| 输入框 Input / 下拉 Select / 文本域 Textarea | 40px / 自适应 | Textarea 最小 6 行 |
| 列表行（问题卡/表行） | ≥64px | 头像 32px 圆形 |
| 标签 chip | 24px | rounded-full，可点击款带 × |
| 分页器 | 40px | 页码 + 上/下一页，超过 7 页折叠省略号 |

### 0.3 三态规范（所有列表/详情必须实现）

| 状态 | 表现 |
| ---- | ---- |
| 加载 | 骨架屏：列表用卡片骨架 ×5，详情用行骨架；**禁止整页转圈** |
| 空 | EmptyState 组件：插画位 + 一句"为什么空" + 一个主操作按钮 |
| 错误 | ErrorState：中文人话提示 + [重试]；500 时表单内容保留（草稿机制，见 2.5/2.7） |

### 0.4 全局共享控件清单（沉淀到 `src/shared/components`）

Button（primary/ghost/danger，含 loading 态）· Input · Textarea · Select · TagChip · Card · Avatar · StateBadge（未解决/已解决/已封禁…）· EmptyState · ErrorState · SkeletonList · Pagination · TabNav · Modal · Drawer · ConfirmDialog · Toast（全局操作反馈）· MarkdownView（渲染前 XSS 清洗）· VoteWidget · UserLine（头像+昵称+角色徽标，点击→用户主页）· FilterBar。

| 控件 | 位置 | 类型/规格 | 交互与去向 | 状态与可见性 |
| ---- | ---- | ---- | ---- | ---- |
| 状态徽标 | 标题右侧 | StateBadge | 采纳成功后"未解决"→"已解决"（联动） | 全角色 |

| 编辑/删除 | 问题操作行 | ghost / danger | 编辑→`/questions/[id]/edit`；删除→ConfirmDialog"删除后不可恢复"→DELETE 后回广场 | **仅作者或管理员**渲染（越权不渲染） |

| 评论区 | 回答卡内折叠 | 评论列表 + Input + [发送] | POST `/api/answers/{id}/comments`；二级回复缩进展示；删除（作者或管理员） | 登录用户可发 |
| 相关问题 | 右栏 | 标题链接 + 元信息 ×5 | →`/questions/[id]` | 同标签取交集，空则隐藏整块 |
| AI 辅助回答 | 右栏 | **暂缓不渲染** | — | 随 Agent 接入补齐 |

### 2.8 编辑问题 `/questions/[id]/edit`

复用 2.6 表单（预填标题/正文/课程/标签）。差异点：顶部面包屑"问题详情 / 编辑"；操作行为 [保存(primary)]→PATCH→回 `/questions/[id]`、[取消(ghost)]→回详情、[删除(danger)]→ConfirmDialog→DELETE→回广场；底部状态行"草稿已自动保存 · 刚刚"（30s 间隔，失败显示"草稿保存失败，请手动复制备份"）。

### 2.9 标签详情 `/tags/[id]`

头卡：标签名 H1 + 描述 + 关联问题数；下方复用问题卡列表（该标签下）+ 分页器；三态齐全。

### 2.10 排行榜 `/rankings`

页内 Tab：**周榜 / 月榜 / 课程榜**（课程榜追加课程 Select）。榜单表（≤72 字符宽）：列 = 名次（前三名红底徽标 1/2/3）· UserLine · 声望值 · 提问数 · 回答数 · 采纳率。行点→`/users/[id]`。Tab 切换写 URL 参数；三态齐全。
