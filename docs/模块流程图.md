### 1.3 图 2：学生端提问与问答闭环（含 AI 确认）

                        │        ├─ 命中 → 跳 F-08（API-17，保留草稿）
                        │        └─ 无依据 → 提示"未找到站内相似问题"
                        ▼
                  校验：标题/正文非空? ── 否 ─▶ 行内红字（E-01，不发请求）
                        │ 是
                        ▼
                API-16 POST /api/questions ──▶ 后端 :8000 ──▶ MySQL
                        │ 200
                        ▼
                跳 F-08 问题详情 ──▶ 自动触发 F-33 标签推荐卡片 ⇠ API-58(SSE)
                        │
                        ├─ 用户勾选后"确认添加" ──▶ API-35 ──▶ 标签落库 ✔

### 1.8 手绘步骤与判读要点（照着画就不会漏）
