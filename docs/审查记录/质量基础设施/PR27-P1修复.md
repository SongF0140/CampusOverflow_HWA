## 决策说明

### P1-1 鉴权头

1. **改为 `"X-Service-Token": config.token`（不带 Bearer 前缀）**。后端 `require_service_token` 走 `secrets.compare_digest` 与 `settings.agent_service_token` 全等比较，带前缀必然 401。头名大小写由HTTP 语义不敏感，但统一用后端文档写法 `X-Service-Token`。
2. **同时删掉 `Authorization` 头**：避免"两个头都在"的歧义，并在测试里断言 `Authorization` 为 `null`，防止将来误加回来。
3. **反向断言写入测试**：`tests/tools-whitelist.test.ts` 原来断言 `Authorization === "Bearer svc-token"`，等于把错误行为锁死；现改为断言 `X-Service-Token === "svc-token"` 且 `Authorization === null`。
4. **放弃的替代方案**：不改后端去兼容 `Authorization`（后端契约已由接口设计指南定案且有测试覆盖，为迁就单侧错误而开兼容分支等于把契约搞成两套）。

### P1-2 错误处理

1. **拆出独立的 `ErrorEnvelopeSchema`**，而不是复用成功信封。根因是复用了同一个 schema：`data: z.unknown()` 让 `message.data.message`在 TS 层非法（编译不过），在运行时也拿不到值（后端 `data`恒为 `null`）。
2. **错误码取 `failure.data.code`（原代码恒取 `response.status`）**：后端信封 `code` 才是业务错误码，`data` 为 null 时 fallback 到 HTTP status。两者一致时行为不变。
3. **新增两条边界测试**：①错误信封 → `InternalApiError` 携带后端 `code=401` 与中文文案；②响应体非合法信封（如裸文本 504）→ fallback `HTTP 504`。第2 条覆盖原代码 `safeParse` 失败分支，此前无测试。
4. **放弃的替代方案**：用 `z.union` 把两个信封合一路由 —— 收益为零，`message` 在两支都是 `z.string()`，直接读顶层即可，不需要 union。

### P1-3 路由守卫跳转目标

1. **直接 `NextResponse.redirect(new URL(decision.destination, request.nextUrl.origin))`**，proxy 不再重新推导跳转目标。`decideGuard` 已完整编码了四种语义（登录页+returnTo / 403 / 角色首页 / 放行），proxy 只做"补origin → 302"的机械动作。
2. **`returnTo` 由 guard 层负责**：用户要求"仅在目标是登录页时才生成 returnTo"—— `guard.ts:71-75` 的 `loginRedirect()` 已经这么做了，proxy 再拼一次就是重复且会覆盖 `/403` 分支。新实现不再引入这条逻辑，职责单一。
3. **删掉 proxy 对 `loginUrlFor` 的 import**：`loginUrlFor` 仍在 `LoginForm` 侧的 `toInternalPath` 校验链路和`redirect.test.ts` 中保留，未删除工具函数本身，只解除 proxy 的错误依赖。
4. **新增 `frontend/src/proxy.test.ts`（6 用例）**：此前只有 `guard.test.ts`（测纯函数），**proxy 本身零覆盖**，正是"destination 被忽略"能通过评审的原因。新测试直接构造 `NextRequest` 断言 `location` 响应头：
   - 未登录 `/teacher/moderation?case_id=1` → `/auth/login?returnTo=%2Fteacher%2Fmoderation%3Fcase_id%3D1`
   - 学生 / 教师访问 `/admin`、`/admin/users` → `/403`，且 **URL 中不含 returnTo**
   - 管理员访问 `/admin`、公开页、已登录访问 `/me` → 200 放行（无 `location`）
   - 已登录访问 `/auth/login` → 按角色送 `/admin` / `/teacher` / `/`
5. **保留 `PUBLIC_PATHS` 常量不动**：它当前在本文件内未被引用（判定逻辑已下沉到 `guard.ts`），属既有状态，本次不顺手清理，避免把缺陷修复与重构混在一个 diff 里。**遗留项**见下。
