# W-02 公共网络检索与只读浏览器工具

## 设计依据

用户确认Tavily结构化搜索与Vercel agent-browser，并要求工具实现共用基类契约、由各端按角色继承。依据最新spec/plan/analyze及设计/实施计划，复用AgentTool、执行网关、请求级身份、预算与审计。新增tools/request-tools.ts供chat/tasks共用；公共只读能力集中于role-capabilities，各角色继承后由主规则与任务类型裁剪，后台治理不扩大工具集。

## 验证记录

- 初始缺失模块、角色未授权及来源/错误脱敏反例失败后实现；新增7文件44项，Agent最终61文件535项全部通过，lint/typecheck通过。覆盖私网/保留IP/IPv4别名、凭据URL、DNS混合私网、重定向重验、正文上限、取消、请求间来源隔离、三角色公共能力与规则撤权、伪造外链及返工约束。
- Hono真实chat路由配合模型/搜索替身验证搜索→正文→回答的顺序、密钥不进入模型输入、伪造来源不发送done或未审查文本。Tavily固定HTTPS协议的fetch替身验证Authorization、公开查询字段和禁用自动答案，错误响应不透出原文；未使用真实Tavily密钥。
- Windows真实CLI读取公开固定HTML并关闭私有会话。Linux首次独立产物反例发现allowed-domains及代理设置会触发Chrome；对照最小命令定位后改为非执行DOM剥离脚本/资源标签，再以本地text/markdown交read --require-md，核对accept-markdown返回，不使用Chrome模式。
- Linux Node24.16.0最终全新npm ci后正式build、Workflow/dev和smoke:web均通过。smoke:web把完整产物移到源码目录外，以真实CLI读取含脚本标记的固定HTML，确认正文存在、脚本标记被剥离且会话正确关闭；探针不在正式产物。

## 决策说明

searchWeb/readWebPage各有一份公共实现，参数不能指定身份；配置未启用/无密钥不展示。网页仅允许本请求已搜索URL，公开客户端固定已核验IP、TLS保留原主机校验，重定向重验且正文最大512KB。CLI不接收外部URL、业务凭据、用户配置或任意命令，只读取一次性loopback文本，私有socket与会话结束后清理。自然语言隐私识别仅有词法拦截和提示约束，不宣称能自动阻止所有隐私查询；管理员需根据资料敏感性启用。动态网页操作、登录和真实提供方质量不在此验收范围。
