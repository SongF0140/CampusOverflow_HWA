# W-01 Agent配套依赖

## 设计依据

用户授权先核对网络检索，缺少则新增工具，并更新Agent浏览器、Workflow等依赖后推送；已确认结构化搜索加agent-browser只读方案，并强调各端共用工具契约、按权限继承。依据AGENTS.md、最新学生权限澄清、实施计划和npm官方元数据。agent-browser0.41.1要求Node24，Workflow5.3.0实际依赖serde5，因此同步更新Agent运行下限、CI及配套包。

## 验证记录

安装后核对实际版本，Linux Node24.16.0全新npm ci可用，当前相关全量535项及lint/typecheck通过；此前同套核心版本的正式构建、Workflow与dev冒烟通过。浏览器源码真实只读与关闭在Windows通过，最终Linux独立产物及PG兼容验证归W-03，尚不据此宣称完整验收。

## 决策说明

保留Hono、业务FastAPI、MySQL与独立Postgres职责，治理预算和逐项审批不变。保留World noExternals及SQL/Graphile资源追踪，为agent-browser添加完整资源追踪。锁定核心配套与网络依赖，其他依赖在兼容范围更新，不通过audit --force降级Workflow或盲目跨工具链大版本；剩余61项上游审计见依赖说明。分块本地提交，最终收口后推送。
