## 决策说明

1. **Loop API 选型**：AI SDK 7 已移除 `maxSteps` 参数，改用 `streamText` + `stopWhen: isStepCount(n)` 实现步数上限停止条件；放弃自行手写 tool-calling 循环（SDK 已覆盖流式与工具编排，手写徒增维护面）。
2. **结构化输出自检**：`generateObject` + Zod parse，校验失败重试一次后仍失败则返回明确错误——不把未校验输出交给调用方（agent端需求文档 §3.1）。
3. **run 摘要先内存实现**：observability 的 run-recorder 本期落内存 Map，接口形状与 T-16 的持久化（POST /internal/agent/runs、/tool-calls）对齐，T-16 换实现不动调用方。
4. **测试策略**：mock LLM 与 mock internal-client，不依赖真实网络与真实 Key（AGENTS.md 硬性约束 8 与 conventions §6）。
5. **放弃的替代方案**：Hono 内置 SSE helper 之外的流式封装不做；agents/ 角色化扩展点保持空目录（spec v3 明确单 Agent 不做多 Agent）。
