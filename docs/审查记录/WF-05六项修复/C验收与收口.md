## 决策说明与限制

可恢复失败仅指已知未执行：申请400/409/422及后端原任务明确invalidated。权限blocked转人工，无法确认回执仍有限核对后人工；错误反馈只含分类与已完成动作，不携带原始异常或凭据。重规划消耗下一轮，完整业务loop仍最多5轮。

旧admin/platform冻结哈希兼容；旧系统待执行申请缺少内容版本时失败关闭，不能自动补字段继承原批准。完整观察使用模式脱敏；超过处理上限转人工，不宣称长文已完整审核。发现检查点仅为业务发现进度，不复制Postgres Workflow运行状态。

真实模型判断质量、生产负载/多实例容量、远端CI和生产灰度未验收；上游Rollup注释/循环chunk、可选pg-native/node:sqlite提示仍存在。全量及真实故障场景通过不等于这些环境已验收。所有新开关默认关闭，本批仅本地提交。临时数据库与测试进程验收后停止，原有数据库服务保持运行。
