# 夜间快照双槽设计

日期：2026-11-18。
状态：S1～S2 已实现并通过冒烟；S3 导出、双槽、候选复核与读取接入已完成（`QA_SNAPSHOT_READ_ENABLED` 默认关闭）；S4 回退接口、到期清理与切换指标已完成（`SNAPSHOT_ADMIN_ENABLED` 默认关闭）。
范围：01:00 冻结知识与问答索引、同进程双槽只读服务、校验后切换、旧槽保留回退。
依据：用户 2026-11-18 决策；`docs/Agent层设计与实施分期.md`；项目宪法 C-05～C-08。

## 一、目标与约束

- 01:00 起冻结当前知识与问答索引，更新期间用快照继续提供**只读问答**。
- 更新结果先进入候选槽，严格过滤与校验通过后才接管主槽。
- 不复制进程：同进程内两个只读槽 + 引用切换；旧槽保留 24 小时可回退。
- 更新失败不切换，旧槽继续服务；不产生半更新状态。
- 快照不包含个人记忆、私人会话、审计与工单。

## 二、时间线

```text
01:00  冻结：记录当前活跃槽版本，进入维护读模式
01:00~ 构建候选槽：重建知识目录与问答索引，逐项过滤
       校验：解析错误为 0、标签白名单、可见性/版本规则
       ├─ 通过：切换活跃槽，旧槽保留 24h
       └─ 失败：丢弃候选槽，旧槽继续服务
切换后 退出维护读模式，主链路承接；旧槽到期自动失效
```

## 三、槽模型

| 槽 | 作用 | 可写 |
| --- | --- | --- |
| active | 当前对外服务 | 否 |
| staging | 夜间构建的候选 | 仅构建任务 |
| previous | 切换前的旧版本，24 小时内可回退 | 否 |

- 同一时刻只允许一个 staging。
- 版本号由内容哈希生成；版本未变化时不切换，避免无意义抖动。
- 回退只能回到 previous，且必须在保留期内。

## 四、快照范围与过滤

| 数据 | 是否进快照 | 过滤规则 |
| --- | --- | --- |
| 教材 Markdown、卡片 | 是 | 解析错误为 0；标签必须在可信词表且课程匹配 |
| 问答索引 | 是（S3） | 仅 visible 且未删除未隐藏；课程权限在查询时仍复核 |
| 个人记忆 | 否 | 浏览器保存，不进入服务端快照 |
| 私人会话/审计/工单 | 否 | 只读快照不承载治理数据 |

严格过滤的含义：任一卡片解析失败或标签越域，整次切换失败，不允许"部分可用"。

## 五、只读服务（S2）

- 维护窗口内允许：问答、知识检索、课程与问题浏览。
- 维护窗口内拒绝：提问、回答、评论、投票、采纳、治理处置、审批执行。
- 拒绝必须返回明确中文提示，不伪装成权限错误。
- 写操作拒绝由后端统一中间件执行，Agent 与前端不各自判断。

## 六、问答索引快照（S3）

- 后端提供只读导出：问题 id、标题、脱敏摘要、标签、课程、版本、更新时间。
- 导出不含正文全文中的隐私字段；可见性以导出时为准。
- Agent 侧建立不可变 pack，按版本号挂到槽上；查询仍经后端复核权限。
- 候选复核接口 `POST /internal/agent/user/qa-index/candidates`：快照只出候选 id，后端按双凭证与当前可见性裁决，带课程时限定课程。
- 读取接入：`searchQuestions` 在开关开启且有活跃快照时，先按标题相关度出候选 id，再经复核接口返回；带标签、无快照、无命中或复核失败一律回退后端检索。
- 包大小上限与分页游标在实施前定案；超限拒绝导出并提示缩小范围。

## 七、失败与可观测

- 快照构建失败：记录版本、错误数、耗时；不切换；次日重试。
- 快照失败不阻塞离线整理（P1 已验证）。
- 每次切换记录：旧版本、新版本、卡片数、耗时、触发来源。
- 保留回退入口（S4）：管理员显式回退，回退后旧槽立即失效。
- 回退入口（S4）：`GET /agent/admin/snapshots` 返回知识与问答双槽及最近指标；`POST /agent/admin/snapshots/rollback` 支持 `target=knowledge|qa`；`SNAPSHOT_ADMIN_ENABLED` 默认关闭，仅 active 管理员可用。
- 到期清理（S4）：读取槽信息或回退时清除过期 previous，并记录 `knowledge_snapshot_previous_expired` / `qa_snapshot_previous_expired`。
- 切换指标（S4）：进程内保留最近一次构建/切换/回退的时间、动作、版本、条数、错误数、成功标记与脱敏原因；随进程重启清空。

## 九、风险与未定项

- 维护窗口结束时间未定，当前为 01:00–05:00；知识切换与维护读模式尚未串联到同一调度流程。
- 问答索引快照为全局导出，principal 不含课程范围；读取一律先经候选复核接口裁决，复核异常时回退后端，禁止直接以快照结果作答。
- 快照检索若接入，只覆盖标题；正文检索仍依赖后端。
- 多实例下槽不共享；跨进程一致性与切换收敛归 T-18。
- 同进程双槽只保证读一致性，不保证构建期间源文件不被外部修改；以内容哈希与版本号识别。
