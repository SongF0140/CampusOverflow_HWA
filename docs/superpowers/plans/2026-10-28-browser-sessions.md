# AX-S 浏览器逻辑会话与渐进记忆实施计划

依据：AGENTS、C-07、AX-R02、Memory M-D01/M-D02/M-D04/M-D05。用户授权本批连续实施至 TW-02；父任务统一回填规格、提交与收口。

## 决策

- 复用现有 /assistant 页面，增加“＋新会话”、切换和清空当前会话。会话只在当前浏览器按账号保存，不跨设备同步，不写服务器共享目录。
- 个人记忆仍手动维护、AI 只读。发送请求时先披露索引（最多 50 条、每条 36 字），再披露已选摘要（最多 5 条、每条 100 字），最后披露已选详情（最多 3 条、每条 500 字）；最终聊天只携带已选详情，三阶段均不读取其他账号。
- 三阶段选择采用确定性文本相关性与偏好优先，仅用于个人记忆装配，不修改教材 RAG 检索策略。无相关记忆时允许空选择。
- 会话 ID 与单次运行 ID 分离；历史仅 user/assistant，两千字单消息、最近 20 条且总 8000 字。历史为不可信上下文，不进规划/共享经验/审计。
- 切换账号、切换会话、清空记忆、清空会话及卸载页面均中止在途请求，旧响应不得回写。
