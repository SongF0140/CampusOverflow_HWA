# 管理员继承教师权限实施计划

用户明确：“管理员权限覆盖教师和自己的新权限”；进一步确认管理员可管理全站课程/班级，变更仍由管理员本人确认。此决定覆盖上一批把教师工具与管理员工具互斥的实现。

## 设计与边界

管理员继承教师业务能力并叠加治理能力：课程/知识树/教学计划、课程周报与匿名反馈、班级名单、通用经验审核、学生回答教学认证、助教资格审核。教师仍仅本人负责课程；学生和助教能力位不被隐式继承。个人记忆、私人聊天和用户归属运行不向管理员开放。课程周报属于本轮全站教学管理范围，替代旧 E-14 对管理员不旁路的课程报告限制。

实际治理/名单确认入口仍不注册给模型或外部MCP；管理员看清单后以本人登录确认，后端重查当前身份。名单保留原申请人，执行审计写真实确认人；重复确认不重放。管理员使用既有教学认证类别字段，界面说明类别包含教师/管理员，避免误认为助教认证。没有新增表或迁移。
