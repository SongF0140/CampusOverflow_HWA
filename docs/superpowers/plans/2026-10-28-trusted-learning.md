# AX-T 可信标签与匿名教学反馈实施计划

依据：spec AX-R03/AX-R04、Memory M-D06、RAG D-019/D-020、宪法 C-05/C-07 与既有课程可见性。用户已确认只用教材/教师词表、教师只能看匿名概括与聚合次数。

采用课程级受控来源关联表，旧 custom 标签不自动信任；负责教师或管理员明确维护来源与有效状态。学生入课后通过双凭证接口提交 event_id/course_id/tag_ids/knowledge_node_ids/question_id，拒绝私人原文与自由摘要。概括由可信标签名称确定性构造；事件不存用户/会话/记忆/历史。event_id 唯一去重，相同ID参数替换拒绝。

按近7天聚合每个可信tag关联事件数，不解释为人数；公开题目链接提交与读取均复核课程和可见性，失效标签不输出。后台周报服务只读匿名聚合，教师读取限本人课程。Agent 周报最终正文附匿名板块，模型不决定计数。
