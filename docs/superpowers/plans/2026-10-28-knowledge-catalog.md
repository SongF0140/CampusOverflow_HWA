# AX-K 知识目录实施计划

日期：2026-10-28。用户授权持续推进到 TW-02，本块由父任务负责规格汇总、服务接线与提交。

## 依据和边界

已读 AGENTS、RAG 树设计 D-003/D-015/D-019/D-020、Memory M-D07/M-D09。只实现本地 Markdown 目录与渐进读取，不实施 embedding、Cross-Encoder 或生成模型检索。标签合法性由后端可信词表快照提供；本地声明不自行授予标签或课程权限。

## 设计

卡片文件位于根目录的 cards/，只允许三个二级标题：领域名称、元数据、摘要。元数据使用 JSON 代码块，包含 course_id、tag_ids、source（textbook/teacher 与来源标识）、body（根目录相对路径、bookmark），可选 year。正文必须有显式 HTML 书签和返回卡片的 Markdown 链接；不会自动改写原始资料。

服务读取只限受控根目录，拒绝逃逸路径与根外符号链接，限制文件大小。扫描计算内容 SHA-256；只对变化卡片重解析，正文变化也更新版本；删除、失效或校验失败即移除旧入口。新目录完整构建后原子替换，对调用者仅返回按已授权课程过滤的目录、卡片或正文。全量目录索引不包含摘要或正文，getCard 披露摘要，getBody 最后披露目标书签段。

刷新采用文件变化通知触发＋定时全量核对，按内容哈希识别漏事件；默认由配置缺省关闭，不自动扫描工作区。getBody 读取时重新核对内容哈希，变更后拒绝旧快照，等待刷新。更新回调传版本号，供主 Agent 更新领域入口。错误对外只报告受控相对路径与错误类别，不含原文。

## 工程决策

- 使用 Node 内置 fs/crypto，不新增依赖。JSON 元数据是第一版明确格式，保留三板块卡片设计；不是宣称用户选择了 JSON 语法。
- trustedTags 是带 course_id 的后端词表输入；未提供可信词表时不能装载带标签卡片。课程范围每次查询显式传入，没有管理员全局旁路。
- 目录为可重建内存快照，Markdown 是真值源；服务重启后重建，不另存第二份数据库。
