# AX-C 主 Agent 共享记忆与子 Agent 权限计划

日期：2026-10-28。依据 Memory M-D07/M-D08/M-D09、宪法 C-05/C-07 和当前工具白名单。父任务负责真实路由、工具注册接线与规格汇总。

共享内容只含领域目录、行为 skill、已发布回答流程经验、工具规则和认证回答卡片。受控 JSON 文件由管理员维护，不允许聊天正文或普通用户请求写入。用户新增决策：Agent 提交经验建议，由老师确认后发布；父任务实现后端发布接口，本模块只接受后端已发布课程经验，按课程范围披露。文件中的旧 experiences 字段不作为老师审批证明，不自动加载为已发布经验。读取计算 SHA-256，版本变化触发主 Agent 重新装配。卡片链接必须经回调核验认证状态、可见性、课程范围后才能披露，不根据模型构造链接。

子 Agent 注册表代理每次展示和每次调用都同步重新取得受控规则，并计算规则允许集、后端 principal 对应角色权限、固定只读工具集的交集。fetchModerationTarget 仅读取后端允许的可见正文，保留其既有普通用户只读用途，不因名字含治理就误禁；治理预览/申请仍由独立管理员 API 控制。medium/high 或未知工具禁止；已装配 SDK execute、getTool.execute 也再次校验，防规则收紧后旧工具引用继续执行。代理不允许子 Agent 注册新工具。角色凭证仍由后端每次内部 API 调用复核，规则不是权限来源。

逐层披露：index 只给领域名/skill/经验/认证卡片索引；第二层仅选中条目的摘要；第三层仅显式请求的规范正文或流程。工具规则不以提示词代替执行器检查。
