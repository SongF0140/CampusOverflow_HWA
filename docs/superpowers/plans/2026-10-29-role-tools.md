# 角色工具与教师班级确认实施计划

用户确认学生只问答、管理员审批后治理；教师可加入/移出本人班级学生，展示变更清单后由该教师确认，不需管理员代审。

实现：模型工具只生成待确认动作，不能伪造批准；管理员复用治理工单和后端 resolve，教师使用独立名单申请/确认。新名单申请冻结课程、学生清单、成员状态版本；确认接口仅开放给真实登录负责教师，不注册为 LLM/MCP 工具。每次执行复核身份/课程归属/名单版本，重复确认返回已完成结果。变更与审计同事务，学生和外部模型不能调用教师确认入口。

- [x] 后端名单申请、版本校验、负责教师确认、取消、重复请求幂等与迁移；权限和状态变化反例先红后绿。
- [x] Agent 按角色注册 proposeGovernance/readGovernanceResult、proposeClassMembership/readClassMembershipResult；学生无写提议工具；主规则只能收窄。
- [x] 计划执行遇到待确认结果停止依赖工具；回答告知申请链接。教师/管理员人类确认仍由界面直接调受保护后端。
- [x] 教师名单变更确认页，管理端沿用审批中心；类型/lint/专项验证并记录限制。
