# Checklist（build-frontend-mvp）

## 基建
- [ ] 共享控件库覆盖控件级设计说明 §0.4 清单，每个控件有 vitest
- [ ] 代码中不存在直连 `:8000` / `:8787` 的地址，所有 fetch 走 BFF
- [ ] 数据 hooks 具备 loading/error/empty 三态且有测试；BFF 注入 Authorization 与 x-trace-id

## 框架与守卫
- [ ] 未登录访问受保护页跳 `/auth/login?returnTo=<原路径>`，登录后回原页
- [ ] 学生访问 `/admin/**`、学生/游客访问 `/teacher/**` 渲染 403 页且不发业务请求
- [ ] 越权入口不渲染（采纳仅提问者、编辑删除仅作者或管理员、管理端入口仅管理员、助教板块仅能力位用户）
- [ ] 学生端顶栏 4 页签 + 搜索框 + 铃铛（未读数、99+）+ 用户菜单按角色渲染；AI 页签不渲染
- [ ] 管理端侧栏 Agent 运行项置灰"二期"；`/me` 的 AI 记忆入口置灰带 tooltip

## 页面功能
- [ ] 登录按角色分流：学生→returnTo 或 `/`、教师→`/teacher`、管理员→`/admin`；401 行内中文提示
- [ ] 注册：用户名/邮箱/密码强度/确认密码校验齐全，成功 Toast 后跳登录
- [ ] 问题广场筛选条件（课程/标签/排序/状态）写入 URL 且刷新可回填
- [ ] 发布问题：标签手动添加 ≤5、重复 400 行内提示、500 保留草稿、localStorage 30s 草稿+恢复询问
- [ ] 问题详情：投票可改票/取消、评论二级回复缩进、采纳后徽标联动"已解决"且按钮消失、认证/推荐徽标条件渲染
- [ ] 课程详情展示四聚合区块真实数据；加入/退出课程按钮状态联动
- [ ] 排行榜周/月/课程榜可切换且写 URL；搜索页历史 chips 可删可清空
- [ ] 通知点击已读并跳来源页；全部已读后红点清零
- [ ] 用户主页与个人中心不暴露邮箱/手机号等隐私字段
- [ ] 教师端课程管理四 Tab 可用；认证页调 certify 接口成功/取消成功
- [ ] 管理端用户管理封禁 Drawer→ban、解禁确认→unban，操作留提示
- [ ] 治理三页（审核队列/审批中心/申诉处理）与教师工单处理为骨架 + 501 兜底空态，不白屏不报错
- [ ] 封禁申诉页提交 501 时提示"接口尚未开放"；未封禁用户看到 EmptyState
- [ ] `/search`、`/action-result` 补录页可用；`/me/memories`、`/admin/agent/**` 路由保留不实现

## 三态与视觉
- [ ] 逐页检查：加载=骨架屏（无整页转圈）、空=EmptyState（原因+主操作）、错误=ErrorState（中文+重试）
- [ ] 状态表达均为"色块+文字"，不只靠颜色
- [ ] danger 操作（删除问题/回答/课程、封禁、移出成员）均有 ConfirmDialog
- [ ] 无大面积蓝紫渐变/玻璃拟态/霓虹发光；强调色只用于主按钮/焦点环/链接
- [ ] 动效带 `motion-reduce:` 降级；≤1024 导航折叠抽屉、右栏下沉
- [ ] 界面文案全简体中文，错误提示为"人话"不展示堆栈

## 门禁
- [ ] `npm run lint` 零 error
- [ ] `npm test`（vitest）全部通过，覆盖 hooks、表单校验、投票/采纳交互（mock 网络）
- [ ] 每板块一次提交 `<type>: <简短中文描述>`，并经人工审查（审查记录入 docs/审查记录/）
- [ ] 接口与后端实现不一致时未私自适配，按"回填 plan §5 + 接口文档 + 重跑 analyze"流程处理
