# 教师端需求文档（业务后端 · 第一期）

> 依据：spec v3（US-10、Q-07；US-13/US-14 二期）｜权威架构：[docs/后端架构说明.md](../后端架构说明.md)｜端总览：[README](./README.md)
> 前端页面为第二阶段；本文档描述第一期后端为教师端提供的全部接口与验收口径。

## 1. 定位与边界

教师端围绕"我的课程"展开：课程管理、课程问答区与学习热点、研究生助教认证审核。审批中心（AI 工单处理）为第二阶段，本期 governance 仅建表 + 501 占位。

**必须做（第一期后端）**：

- 课程创建 / 编辑 / 成员查看，**仅限本人负责的课程**（E-06，service 层校验，管理员除外）。
- 助教认证审核：通过后由 identity 置位助教能力位，学生端助教板块接口即时解锁。
- 课程学习热点读取（discovery 纯读，不提供独立写接口）。
- 审核操作写入审计日志。

**禁止做（硬边界）**：

- 不修改、不管理他人负责的课程（E-06；管理员不受此限）。
- 不在本端提供内容处置动作（隐藏 / 删除 / 封禁属管理员端）。
- 认证审核接口不返回身份证件等隐私原文，只返回身份类型与认证状态。

## 2. 使用者与触发来源

| 角色 | 能力 | 说明 |
| ---- | ---- | ---- |
| teacher | 课程管理 + 助教认证审核 | 注册时角色选择教师（US-02） |

触发来源：课程管理操作；研究生提交助教认证后的审核操作（认证申请提交入口随 T-02a 落定）。

## 3. 功能需求

### 3.1 我的课程管理（US-10、E-06）

| 功能 | 说明 |
| ---- | ---- |
| 课程创建 / 编辑 | 教师创建并维护本人课程 |
| 成员查看 | 课程成员列表（教师 / 管理员可见） |

验收标准：

- 教师不能管理他人负责的课程（管理员除外）；越权返回 403。
- 接口测试通过。

### 3.2 课程问答区 · 学习热点（US-10、US-09）

| 功能 | 说明 |
| ---- | ---- |
| 课程问答区 | 课程内问题列表（复用 `/api/courses/{id}/questions`） |
| 学习热点 | 高频问题、热门标签（`sort=hot`，discovery 纯读） |

验收标准：聚合数据与 `sort=hot` 排序正确；教师无额外写权限（与管理员一致走通用接口）。

### 3.3 研究生助教认证审核（Q-07、US-20 前置）

| 功能 | 说明 |
| ---- | ---- |
| 认证申请查看 | 研究生身份认证申请列表 / 详情（身份类型 + 认证状态） |
| 审核通过 | identity 置位助教能力位 → 该用户学生端助教板块接口即时解锁（`require_graduate_assistant` 放行） |
| 审核驳回 | 维持未认证状态 → 助教板块接口维持 403 |

验收标准：

- 审核操作留审计日志（操作者 / 时间 / 对象 / 结果）。
- 通过后三类身份边界（本科生 / 未认证研究生 / 已认证研究生）行为符合 T-02a 的 pytest 预期。
- 接口路径归属 `/api/users` 前缀（identity 模块），具体路径随 T-02a 实施落定并回填 `plan.md` 第 5 节。

### 3.4 审批中心 · 工单处理（US-13、US-14）【第二阶段】

第一期不实现：governance 仅建表（ModerationCase / Appeal）+ 路由 501 占位。第二阶段随 T-15 交付：AI 创建的待确认工单由教师 / 管理员在审批中心处理（七类处置动作），全部处置留审计。

## 4. 接口需求（对外提供，`/api/*`）

| 接口 | 方法 | 说明 | US / 模块 |
| ---- | ---- | ---- | -------- |
| /api/courses | POST | 创建课程（仅教师） | US-10 / courses |
| /api/courses/{id} | PATCH | 编辑课程（仅本课程教师） | US-10 / courses |
| /api/courses/{id}/members | GET | 课程成员列表 | US-10 / courses |
| /api/courses/{id}/questions | GET | 课程问答区（`sort=hot` 取学习热点） | US-10、US-09 / courses + discovery |
| 助教认证申请列表 | GET | 研究生认证申请（路径随 T-02a 落定，`/api/users` 前缀） | Q-07 / identity |
| 助教认证审核 | POST | 通过 → 置位助教能力位；驳回 → 维持 403（路径随 T-02a 落定） | Q-07 / identity |
| /api/governance/*（占位） | 任意 | 第一期返回 501，业务逻辑二期 | US-13/US-14 / governance |

## 5. 非功能需求

- **测试**：pytest 覆盖教师越权管理他人课程（403）、认证审核状态流转、审计日志写入。
- **审计**：认证审核与（二期的）工单处置均落审计日志，记录操作者 / 时间 / 对象 / 结果。

## 6. 一期验收清单

- [ ] 教师创建 / 编辑课程与成员查看可用，越权管理他人课程被拒（E-06）
- [ ] 助教认证审核通过后，该研究生助教板块接口解锁；驳回后维持 403
- [ ] 审核操作留审计日志
- [ ] `/api/governance/*` 占位路由返回 501，表结构已建
- [ ] `uv run ruff check .` 零 error
