# 功能规格（Spec）

## 2026-10-29 治理执行Loop、安全Hooks与管理员存储修订（已确认，待实现）

- GL-R01：高风险治理调用在管理员端弹出目标、动作、期限与影响清单；管理员明确批准该次调用后才可放行，关闭弹窗不等于批准。批准后由受控执行器调用工具封装的后端API，核对结果并续接有界loop。一次批准不授予后续动作通用权限。
- GL-R02：批准、实际执行和结果反馈状态必须区分。执行前重新校验当前有效身份、实际批准、冻结参数、资源范围和目标状态；已执行动作不重放，结果未知先核对，不凭超时推断失败后重复处置。
- GL-R03：聊天、后台巡检、中台MCP和恢复入口受同一可检查安全策略约束；拒绝或检查失败不得绕过。模型和外部密钥不能伪造人工批准。
- GL-R04：人工等待释放连接，审批和执行记录在服务器持久保存；浏览器退出不丢失待执行任务。首批只迁移治理执行流程，名单和经验业务保持现有人工确认方式；旧工单不能被新通道重复执行。
- GL-R05：管理员自己的个人记忆和会话改为服务端持久保存；管理员端与大系统中台来源会话隔离存放，按来源、客户端、账号和会话检查权限。同一管理员映射身份不等于可跨来源读取记忆或聊天。学生/教师个人记忆和会话仍沿用浏览器方案。均支持本人授权范围内查看、删除和清空。
- GL-R06：旧管理员浏览器数据不静默上传；迁移须由本人明确选择，不因新存储启用而上传其他角色或中台私人数据。个人上下文不进入公共记忆或治理审计。

本节记录最新需求，不代表GL执行通道、hooks或服务端私人上下文存储已经实现；历史“全部个人记忆存浏览器”仅对学生/教师继续有效。

## 2026-10-29 角色工具能力修订（用户确认）

管理员权限覆盖教师业务权限并叠加管理员治理权限，作用于全站课程/班级。名单变更由实际登录管理员本人确认后执行，经验可由管理员审核发布；课程教学管理、周报/匿名反馈、回答教学认证与助教资格审核同样继承。教师仍限负责课程，私人会话/记忆与用户归属运行的账号隔离不因此改变；不自动取得学生/助教能力位。此决定覆盖旧管理员不旁路课程周报的限制。

- 学生 Agent 只提供学习提问能力，可内部使用检索/读取工具辅助回答，不通过工具修改课程、名单或执行治理。
- 管理员 Agent 可提出治理、删除和修改动作；必须先展示变更并获得人工批准，后端复核身份、参数与现状后执行，已执行动作不重放。
- 教师 Agent 可将学生加入或移出自己负责的课程/班级。先展示学生与班级的变更清单，由该负责教师明确确认后后端执行，不要求管理员代审；不能管理其他教师的班级。
- 此决定细化 AX-R08：仅学生工具集限定只读问答；教师/管理员可拥有角色允许的受确认写能力，主 Agent 不能突破后端授权。

- **AX-R02 独立会话**：用户点击“＋”建立独立会话；历史、运行状态与上下文按账号/会话隔离。同账号个人记忆按需渐进披露，不一次性加载全部记忆。

- **AX-R04 可信标签**：本轮新增知识检索和学习反馈只使用教材及教师维护的有效词表。模型不可编造标签或未经确认创建词表项，匹配不到时如实说明。旧问答自定义标签业务不因本条被整体删除。
- **AX-R05 治理审批**：治理前查询后端现状，向管理员展示事实、拟执行动作及影响；确认前停止相关动作，等待不占连接。确认后复用后端治理能力并复核权限与目标状态，已执行动作不重复执行。后台巡检不阻塞前台聊天。
- **AX-R06 外部管理员接入**：外部 Agent 经有效专属凭证取得管理员能力，身份/权限必须由后端可验证的授权映射确定；错误或撤销凭证拒绝。高风险动作仍保留人工确认，不能由模型声明批准。
- **AX-R07 身份管理**：账号角色等受保护身份字段由管理员管理，保留教师审核助教资格。客户端、模型、记忆均不能改写后端身份或权限。
- **AX-R08 主 Agent 记忆与子 Agent 能力**：主 Agent 共享记忆限知识领域、道德/行为 skill 披露、回答流程经验、工具调用规则及优质认证回答链接。按需披露认证链接并引导子 Agent 跳转复用；主 Agent 在后端授权内裁剪角色工具：学生仅问答和内部读取/搜索，教师及管理员的角色动作须由对应人员确认。分配不能突破后端权限；领域、规则及已发布经验变化更新上下文，私人记忆与会话不成为共享经验。

## 1. 功能概述

CampusOverflow AI 是面向高校课程场景的问答平台：学生围绕课程提问、回答、评论、投票和采纳答案，教师认证优质内容并查看学习热点，管理员治理用户与内容。系统角色为学生、教师、管理员三类；研究生不是独立角色，其助教认证通过后获得助教能力，在学生端解锁助教板块（回答问题并标记推荐优质回答），本科生永远不出现该板块。系统引入受控 AI 助手（Agent，第二阶段接入）：它只做检索、推荐、预警和草稿生成，**永远不直接修改核心业务数据**，中高风险动作只能生成待人工确认的工单。第一阶段只做业务后端（Agent 不搭建，治理逻辑仅建表与接口占位）；本规格覆盖第一阶段范围并标注第二阶段条目（见需求文档第 8 节）。

## 3. 主流程

问答闭环（US-02~US-09）：

1. 用户注册登录，选择课程，提交问题（标题、正文、标签），系统保存并展示。
2. （第二阶段）AI 助手在提交前推荐相似问题，提交后推荐标签，**均需用户确认**，系统不自动写入；第一阶段直接提交，不做 AI 推荐。
3. 用户回答、评论、投票；提问者采纳一个最佳答案，仅回答者获得 +15 声誉并生成流水；被采纳通知随 T-10 交付。允许自投、自采纳及负分。问题点赞不加分且不产生流水，回答点赞作者 +10，问题或回答被踩作者 -2；取消投票冲销原积分，改票先冲销旧票再计新票。
4. 被采纳答案在问题详情页突出展示，问题状态变为已解决。

内容治理闭环（US-13/US-14/US-16；第二阶段——第一阶段仅建治理表与接口占位，封禁由管理员直接执行）：

1. 用户发布内容，系统先保存展示，AI 助手随后静默检测。
2. 按风险等级：低风险仅打标记录；中高风险生成审核工单（附快照与原因）并通知管理员。
3. 管理员/教师在审批中心处理工单，系统记录处理结果并通知当事人。
4. 被处置用户可提交申诉，管理员复核后更新结果。

知识树与教学改进闭环（US-21~US-23；第二阶段，KN-R01~03）：

1. 课程负责教师粘贴教材大纲文本，AI 分析产出知识点建议清单；教师勾选确认后，系统按二叉搜索树组织知识点构建课程知识树，学生随课程读取权限可见。
2. 系统每周自动对比近 7 天学生提问与知识树：归纳"提问集中但未覆盖"的主题（附拓宽建议）与各知识点提问热力分布，生成归属负责教师的私有周报。
3. 教师在周报页把差距一键加入教学计划（教学计划条目含手动创建与周报来源两类），并可确认把建议主题作为新知识点写入知识树（拓宽）；AI 建议与系统分析不经教师确认不产生任何写入。

## 4. 边界条件

| 编号 | 场景 | 系统行为 |
| ---- | ---- | -------- |
| E-01 | 标题或正文为空时提交问题/回答/评论 | 不能提交，按钮禁用并提示必填 |
| E-02 | 内容超长 | 截断并提示长度上限 |
| E-03 | 同一问题重复绑定同一标签 | 拒绝并提示已绑定 |
| E-04 | 对同一内容重复投票 | 保持唯一有效投票，允许修改或取消 |
| E-05 | 已有被采纳答案时再次采纳 | 拒绝（一个问题最多一个采纳答案） |
| E-06 | 无权用户尝试采纳、认证、管理他人课程等越权操作 | 拒绝并提示无权限 |
| E-07 | 被封禁用户发帖、回答、评论、投票 | 拒绝并提示原因 |
| E-08 | 未登录用户执行受保护操作 | 引导至登录页 |
| E-09 | AI 推荐标签未经用户确认 | 不写入任何标签关系 |
| E-10 | 作者/管理员软删除问题、回答、评论 | 普通列表与详情不可见，管理员可追溯；删除已采纳回答撤销采纳引用并回退问题为未解决，不冲销历史 +15；回答投票及公开回答计数仅检查回答自身软删，不额外受父问题软删限制 |
| E-11 | 用户查看他人通知/积分流水 | 拒绝，仅本人可见 |
| E-12 | 本科生或未通过助教认证的研究生访问助教板块 | 拒绝访问，前端不出现该板块入口 |
| E-13 | 研究生助教标记"推荐回答" | 仅作展示标记，不影响提问者的采纳权与问题状态 |
| E-14 | 非课程负责教师管理知识树、教学计划或查看周报 | 拒绝；周报仅课程负责教师本人可见，不因管理员角色旁路（与运行归属私有口径一致） |
| E-15 | 向课程知识树写入重复知识点 | 拒绝并提示已存在 |
| E-16 | 删除仍有子节点的知识树节点 | 拒绝并提示先处理子节点 |
| E-17 | AI 分析的知识点建议未经教师确认 | 不产生任何知识树或教学计划写入 |
| E-18 | 同一课程同一周重复生成周报 | 幂等：不重复生成，调度重启不产生重复周报 |
| E-19 | 课程尚无知识树时触发周报生成 | 跳过该课程并记录，不视为失败 |

## 5. 异常场景

| 编号 | 场景 | 系统行为 |
| ---- | ---- | -------- |
| X-01 | 存储不可用 | 提示"服务暂时不可用，请稍后重试"，本地保留未提交草稿 |

| X-04 | 数据不合法/关联损坏 | 回退默认状态并提示，不展示错误堆栈 |

| X-07 | 周报调度或生成失败（模型/后端不可用等） | 不影响问答主流程；单课程失败不阻塞其他课程，失败原因可追溯，下个周期自动重试 |
| X-08 | 大纲分析失败（模型不可用、文本非法） | 返回暂不可用提示，不产生任何知识树写入 |

- **新增推荐、尚未批准的产品语义**：搜索词去空白后1～100字、按普通文本匹配；相关问题可跨课程，优先共有标签多者，再以热度/时间/编号消除并列；课程热门与高频暂共用热度结果，标签按本课程问题使用数、活跃用户按累计可见提问与回答数，各最多10项，不统计评论或投票；通知用固定短文案，内容删除后通知保留但点击遵循原内容可见权限。这些选择需人工审查，不默认转为既有规则。
