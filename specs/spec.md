## 1. 功能概述

CampusOverflow AI 是面向高校课程场景的问答平台：学生围绕课程提问、回答、评论、投票和采纳答案，教师认证优质内容并查看学习热点，管理员治理用户与内容。系统角色为学生、教师、管理员三类；研究生不是独立角色，其助教认证通过后获得助教能力，在学生端解锁助教板块（回答问题并标记推荐优质回答），本科生永远不出现该板块。系统引入受控 AI 助手（Agent，第二阶段接入）：它只做检索、推荐、预警和草稿生成，**永远不直接修改核心业务数据**，中高风险动作只能生成待人工确认的工单。第一阶段只做业务后端（Agent 不搭建，治理逻辑仅建表与接口占位）；本规格覆盖第一阶段范围并标注第二阶段条目（见需求文档第 8 节）。

## 3. 主流程

问答闭环（US-02~US-09）：

1. 用户注册登录，选择课程，提交问题（标题、正文、标签），系统保存并展示。
2. （第二阶段）AI 助手在提交前推荐相似问题，提交后推荐标签，**均需用户确认**，系统不自动写入；第一阶段直接提交，不做 AI 推荐。
3. 其他用户回答、评论、投票；提问者采纳一个最佳答案，系统同步变更双方声誉并生成流水与通知。
4. 被采纳答案在问题详情页突出展示，问题状态变为已解决。

内容治理闭环（US-13/US-14/US-16；第二阶段——第一阶段仅建治理表与接口占位，封禁由管理员直接执行）：

1. 用户发布内容，系统先保存展示，AI 助手随后静默检测。
2. 按风险等级：低风险仅打标记录；中高风险生成审核工单（附快照与原因）并通知管理员。
3. 管理员/教师在审批中心处理工单，系统记录处理结果并通知当事人。
4. 被处置用户可提交申诉，管理员复核后更新结果。

## 4. 边界条件

| 编号 | 场景 | 系统行为 |
| ---- | ---- | -------- |
| E-01 | 标题或正文为空时提交问题/回答/评论 | 不能提交，按钮禁用并提示必填 |
| E-02 | 内容超长 | 截断并提示长度上限 |
| E-03 | 同一问题重复绑定同一标签 | 拒绝并提示已绑定 |
| E-04 | 对同一内容重复投票 | 保持唯一有效投票，允许修改或取消 |
| E-05 | 已有被采纳答案时再次采纳 | 拒绝（一个问题最多一个采纳答案） |
| E-06 | 无权用户尝试采纳、认证、管理他人课程等越权操作 | 拒绝并提示无权限 |
| E-07 | 被封禁用户发帖、回答、评论、投票 | 拒绝并提示原因 |
| E-08 | 未登录用户执行受保护操作 | 引导至登录页 |
| E-09 | AI 推荐标签未经用户确认 | 不写入任何标签关系 |
| E-10 | 作者/管理员软删除问题、回答、评论 | 普通列表与详情不可见，管理员可追溯 |
| E-11 | 用户查看他人通知/积分流水 | 拒绝，仅本人可见 |
| E-12 | 本科生或未通过助教认证的研究生访问助教板块 | 拒绝访问，前端不出现该板块入口 |
| E-13 | 研究生助教标记"推荐回答" | 仅作展示标记，不影响提问者的采纳权与问题状态 |

## 5. 异常场景

| 编号 | 场景 | 系统行为 |
| ---- | ---- | -------- |
| X-01 | 存储不可用 | 提示"服务暂时不可用，请稍后重试"，本地保留未提交草稿 |
| X-02 | AI 助手服务不可用 | 基础问答功能完全不受影响，AI 功能入口提示暂不可用 |
| X-03 | 内容包含脚本代码 | 清洗后安全展示，不执行任何脚本 |
| X-04 | 数据不合法/关联损坏 | 回退默认状态并提示，不展示错误堆栈 |
| X-05 | MCP 外部工具调用失败（第二阶段） | 不影响核心问答业务，记录失败原因供管理员查看 |
| X-06 | 记忆写入包含密码、密钥、隐私原文 | 拒绝写入并记录拦截日志 |

## 7. 验收标准

- [ ] 主流程可演示（第一阶段）：注册 → 提问 → 回答 → 评论 → 投票 → 采纳 → 通知与声誉流水 → 搜索筛选（AI 推荐确认环节第二阶段补入）。

- [ ] 治理流程可演示（第二阶段）：发布风险内容 → 生成含快照的审核工单 → 管理员处理 → 通知 → 申诉；第一阶段仅验证治理表与 501 占位。
- [ ] 边界条件 E-01~E-13 逐项可验证（AI 相关项随第二阶段）。
- [ ] 异常场景 X-01~X-06 逐项可验证（X-05/X-06 随第二阶段）。
- [ ] （第二阶段）AI 助手在所有场景下均不直接修改核心业务数据：高风险动作仅产生待确认工单（US-11/12/13/17/18）。
- [ ] （第二阶段）每次 AI 运行、工具调用、审批请求可按 trace 标识检索（US-18）。
